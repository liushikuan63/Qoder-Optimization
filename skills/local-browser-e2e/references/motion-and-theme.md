# 动效与主题的可观察验收

仅在本次涉及动画、SVG 或主题变化时使用。根据作品用途选择相关检查，不要求所有页面增加控件、次级动画或固定美术元素。

- **主题效果**：比较主题切换前后目标文字、背景的计算样式。只看到 class 或自定义属性变化不能证明视觉颜色已变化；继承的 color 可能已在祖先处计算，需在重定义变量的作用域重新声明实际用色。涉及 transition 时等待相应结束状态，不把同一时刻的起始值当作最终效果。
- **动画效果**：同时核对预期状态及实际属性随时间的变化。离散关键帧、对称图形或暂停状态下两次采样相同并不自动说明失败；选择能区分状态的采样位置或在自有副本中使用不对称标记。不能只靠 running 动画数量或静态截图下结论。
- **SVG 几何**：getBBox 使用局部坐标，不计元素及祖先变换；核对屏幕位置或旋转轴心时使用适当坐标变换、屏幕边界和图像证据。普通 DOM 查询不能观察到的实例内容不能直接认定未运行。
- **循环接缝**：按一周期首尾及接缝两侧的图像/几何验证平铺覆盖、位置和必要的切线连续性。周期由实际设计决定，不机械加固定误差阈值；物理拟真场景才核对转速与移动速度等关系。
- **用户控制**：根据实际需求核对播放/暂停、状态语义与 reduced-motion；减少动画时仍保留主题、表单等无关功能。采用窄屏视口检查溢出与遮挡，不为装饰挤掉核心信息。

以上方法提炼自用户提供 DSH 包的 frontend-motion-delivery，已去掉其特定作品标准、固定数值与平台假设，并独立改写。来源记录包含主题继承与 SVG 边界的自有页面探针；它不替代本包或当前真实项目验收。循环接缝、轴心和无障碍效果仍须随任务验证。

参考：[CSS 属性值处理](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascade/Property_value_processing)、[SVG getBBox](https://developer.mozilla.org/en-US/docs/Web/API/SVGGraphicsElement/getBBox)。
