# 失败处理与复盘模块

## 审核被驳回处理流程

### 标准处理4步

```
第1步：读懂驳回原因（30分钟）
├── 打开 mp.weixin.qq.com → 版本管理 → 审核记录
├── 逐字读驳回理由（不要扫一眼就开始改）
├── 截图保存（后续对比用）
├── 如果有截图标注 → 放大看标注位置
└── 记录：驳回时间、驳回理由原文、涉及页面/功能

第2步：定位问题（1-2小时）
├── 把驳回理由翻译成具体问题（见下方翻译表）
├── 在真机上复现审核员看到的问题
├── 检查是否还有其他类似问题（审核员可能只写了一个）
├── 列出所有需要修改的点
└── 如果看不懂驳回理由 → 在审核记录页面点"反馈"询问

第3步：修复（按问题复杂度）
├── 简单问题（文案/图片/配置）→ 当天改完
├── 中等问题（功能调整/流程修改）→ 1-3天
├── 复杂问题（架构/合规/资质）→ 按实际评估
├── 改完后自测：
│   ├── 用审核员视角走一遍（首次使用、无缓存、新设备）
│   ├── 检查所有页面/功能是否正常
│   ├── 确认没有引入新问题
│   └── 让一个没用过的人试一下
└── 写修改说明（提审时附上）

第4步：重新提交
├── 版本号+1（不要覆盖）
├── 提审备注写清楚改了什么：
│   "针对上次驳回问题已修改：
│    1. [问题1] → 已修改为[具体改动]
│    2. [问题2] → 已修改为[具体改动]
│    请审核，谢谢。"
├── 提交时间：工作日上午（审核员精力最好）
└── 提交后不要反复撤回重提（会重置排队）
```

### 提审备注模板

```
【修改说明】
本次提交针对审核驳回意见进行了以下修改：

1. 驳回问题：[原文引用]
   修改内容：[具体做了什么改动]
   修改位置：[哪个页面/功能]

2. 驳回问题：[原文引用]
   修改内容：[具体做了什么改动]
   修改位置：[哪个页面/功能]

已确认所有功能正常运行，无其他违规内容。
```

## 常见模糊驳回理由翻译

### 审核员写的 vs 实际问题

| 驳回理由（原文） | 实际可能的问题 | 怎么排查 |
|----------------|--------------|---------|
| "内容不符合规范" | ①有违规分享文案 ②有虚假奖励 ③有违规内容 ④有未授权IP | 全文搜索"分享""转发""免费""100%"；检查所有图片 |
| "存在违规引导行为" | ①"分享到X个群" ②"邀请好友得XX"文案太露骨 ③强制关注 | 检查所有分享相关文案和流程 |
| "游戏内容不完整" | ①有空页面/按钮点了没反应 ②新手引导走不完 ③有"敬请期待"占位 | 每个按钮都点一遍，每条路径都走一遍 |
| "存在虚拟支付违规" | ①个人主体有内购 ②虚拟货币可兑换 ③有第三方支付入口 | 检查所有付费相关功能 |
| "类目不符" | ①游戏选了工具类目 ②有违规嫌疑选了休闲 ③实际内容和申报不一致 | 检查后台类目设置，确认和游戏内容匹配 |
| "存在广告违规" | ①广告遮挡核心操作 ②开屏强制广告 ③广告占比>50% | 检查广告位设计，数一下广告触发频率 |
| "隐私合规问题" | ①没有隐私弹窗 ②收集信息没告知 ③隐私政策链接打不开 | 检查首次启动流程+隐私政策页面 |
| "存在BUG影响体验" | ①审核员遇到了崩溃 ②某功能卡死 ③加载失败无重试 | 用全新账号+低端机跑一遍完整流程 |
| "未成年人保护不完善" | ①没有实名 ②没有时长限制 ③没有付费限制 | 检查防沉迷全流程 |
| "界面/功能体验不佳" | ①UI太丑/太乱 ②操作无反馈 ③加载无进度条 | 这是主观理由，优化视觉和交互 |

### 最坑的驳回："内容不符合规范"

```
这个理由=驳回原因较为笼统。排查清单：

□ 所有文案中有没有使用广告法禁止的绝对化用语（"最好""第一"等宣称表述）
□ 有没有"分享到X个群获得XX"（违规分享奖励）
□ 有没有"100%中奖""必得大奖"（虚假宣传）
□ 有没有未授权的卡通形象/品牌logo
□ 有没有违规视觉表现（哪怕是卡通的）
□ 有没有违规机制（随机抽取概率不公示）
□ 有没有"加微信""加QQ"等站外引流
□ 有没有违规相关内容（地图/标识等）
□ 背景音乐有没有版权（用免费音乐库）
□ 字体有没有版权（用免费商用字体：思源/阿里巴巴普惠体）

如果全部排查完还是找不到 → 在审核记录页点"反馈"，礼貌询问具体问题
```

## 连续驳回处理

### 驳回次数对应策略

| 次数 | 策略 | 具体行动 |
|------|------|---------|
| 第1次 | 正常处理 | 按标准4步流程，大概率是具体问题 |
| 第2次（同一理由） | 说明没改到位 | 重新理解驳回理由，可能理解错了；换个人看 |
| 第2次（不同理由） | 说明问题多 | 全面自查，不要只改驳回的那一个 |
| 第3次 | 触发紧急会诊 | 见下方专家团会诊流程 |
| 4次+ | 考虑方向性错误 | 可能产品本身有合规硬伤，需要重新评估 |

### 3次驳回：专家团紧急会诊

```
触发条件：同一版本被驳回3次，或累计被驳回5次

会诊流程：
1. 小林（合规）主导：
   - 逐条分析所有驳回记录
   - 对比微信审核规范逐条自查
   - 判断是否存在"审核员主观判断"因素
   - 给出：是产品问题还是沟通问题

2. 老陈（技术）辅助：
   - 检查是否有技术层面的问题（崩溃/白屏/加载失败）
   - 用审核环境模拟（iOS+Android+低端机）
   - 检查是否有隐藏bug只在特定条件触发

3. 老周（策划）辅助：
   - 检查游戏内容是否有违规/歧义
   - 检查文案是否有违规引导嫌疑
   - 检查玩法是否有违规嫌疑

4. 输出：
   - 问题根因（到底是什么问题）
   - 修改方案（具体改什么、怎么改）
   - 提审策略（要不要换审核时间/要不要附更多说明）
   - 最坏打算（如果改不了，有没有替代方案）

5. 如果判断是"审核员误判"：
   - 在提审备注中详细解释设计意图
   - 附上合规依据（引用微信规范原文）
   - 如果确实误判 → 通过"反馈"渠道申诉
   - 申诉语气：陈述事实，不要情绪化
```

### 申诉模板（确认是误判时用）

```
尊敬的审核团队：

我们的游戏[名称]在[日期]被驳回，驳回理由为"[原文]"。

经仔细排查，我们认为该功能/内容符合规范，理由如下：
1. [具体说明为什么合规]
2. [引用微信规范原文/官方文档]
3. [如有同类已上线产品，举例说明]

我们已确保：
- [合规点1]
- [合规点2]
- [合规点3]

恳请重新审核。如仍有问题，烦请告知具体不合规之处，我们立即修改。

谢谢！
```

## 上线后表现差的诊断路径

### 诊断总流程

```
数据差 → 先确定"差在哪个环节" → 针对性解决

新增少？→ 获客问题（看growth.md）
次留低？→ 新手体验问题（路径A）
时长短？→ 核心玩法问题（路径B）
传播差？→ 社交设计问题（路径C）
变现差？→ 广告/付费设计问题（路径D）
```

### 路径A：次留低（<25%）

```
诊断步骤：
1. 看新手引导完成率
   - <60% → 引导有问题
     ├── 步骤太多（>7步）→ 砍到5步以内
     ├── 有bug卡住 → 修复
     ├── 文字太多没人看 → 改成动画引导
     └── 没有跳过按钮 → 加上
   
2. 看首关通过率
   - <70% → 第一关太难
     ├── 降低敌人数量/血量
     ├── 增加引导提示
     └── 第一关改成"教学关"（必赢）
   
3. 看首次会话时长
   - <3分钟 → 用户不知道干什么/没被吸引
     ├── 前30秒有没有"爽点"
     ├── 目标是否清晰（"做什么"是否明确）
     └── 反馈是否及时（操作有没有即时响应）
   
4. 看加载时间
   - >5秒 → 加载太慢，人走了
     ├── 优化主包大小
     ├── 加loading动画（感知等待）
     └── 首屏资源压缩

修复优先级：加载速度 > 引导流程 > 首关难度 > 首屏吸引力
```

### 路径B：时长短（<5分钟）

```
诊断步骤：
1. 看核心循环是否成立
   - 用户在一个循环里待多久？
   - 循环：操作→反馈→奖励→新目标→操作
   - 如果"奖励"环节弱 → 加强正反馈（音效/特效/数字跳动）
   - 如果"新目标"环节弱 → 加下一步指引
   
2. 看内容深度
   - 用户玩到第几关/第几层就走了？
   - 如果前5关就走 → 内容太浅/难度太平
   - 加入：难度曲线、新机制解锁、收集要素
   
3. 看是否有"中断点"
   - 体力用完？→ 等待时间太长（改为5分钟/颗）
   - 广告太多？→ 减少强制广告
   - 不知道下一步做什么？→ 加任务系统
   
4. 看竞品时长
   - 同品类头部产品时长是多少？
   - 如果你做的是"超休闲"（<3分钟正常）就不用焦虑

修复优先级：核心循环反馈 > 内容深度 > 目标引导 > 减少中断
```

### 路径C：传播差（分享率<5%）

```
诊断步骤：
1. 分享入口是否明显？
   - 用户能看到分享按钮吗？
   - 是否在情绪高点有分享引导？（通关/破纪录/获得稀有物品）
   - 不要只在设置页放一个"分享"按钮
   
2. 分享动力是否足够？
   - 用户为什么要分享？
   - 炫耀（我得了高分）→ 需要成绩图/排行
   - 求助（帮我一下）→ 需要社交助力玩法
   - 挑战（你能超过我吗）→ 需要对比机制
   - 如果都没有 → 用户没有分享理由
   
3. 分享卡片是否吸引？
   - 标题有没有让人想点？
   - 图片好不好看/有没有信息量？
   - 测试方法：把自己的分享卡片发到群里，看有没有人点
   
4. 回流体验是否好？
   - 点了分享链接进来看到什么？
   - 如果是一个空白加载页 → 流失
   - 应该直接看到"你朋友XXX邀请你挑战"

修复优先级：分享触发点 > 分享动力 > 卡片优化 > 回流体验
```

### 路径D：变现差（eCPM<20元或渗透<30%）

```
诊断步骤：
1. 广告位设计
   - 有几个广告位？（至少3个：激励视频+插屏+Banner）
   - 激励视频触发点是否自然？
     ├── 复活（失败后"看广告复活"）
     ├── 双倍奖励（通关后"看广告翻倍"）
     ├── 免费道具（"看广告获得提示"）
     └── 加速（"看广告跳过等待"）
   - 触发时机是否在需求点？（不是随便弹）
   
2. 广告填充率
   - <90% → 接入多家广告平台bidding
   - 多家广告平台聚合（至少2家）
   
3. eCPM低
   - 用户质量差（买量来的低质量用户）→ 优化获客
   - 广告展示太频繁（用户麻木）→ 降频提质
   - 品类问题（工具类eCPM天然低）→ 接受现实
   
4. 渗透率低
   - 用户不知道能看广告 → 入口更明显
   - 奖励不够吸引 → 加大奖励力度
   - 广告加载太慢 → 预加载

修复优先级：增加触发点 > 优化奖励 > 多平台bidding > 预加载
```

## 什么时候该放弃

### 诚实判断标准

| 信号 | 判断 | 建议 |
|------|------|------|
| 次留<15%，改了3版还是<15% | 核心玩法不成立 | 放弃这个玩法，保留技术积累 |
| 上线3个月，DAU从未超过100 | 产品+增长都有问题 | 评估是产品问题还是推广问题 |
| 月收入<100元，且看不到增长趋势 | 投入产出严重不对等 | 考虑止损 |
| 已经投入>6个月，没有任何正反馈 | 方向可能错了 | 认真复盘，不要沉没成本谬误 |
| 做到一半发现合规硬伤（如需版号但拿不到） | 客观条件不允许 | 立即停止，不要抱幻想 |
| 团队/个人已经完全没有热情 | 强撑做不出好东西 | 休息，然后决定是暂停还是放弃 |
| 市场已经饱和，头部垄断 | 小团队没有机会 | 换品类/换方向 |

### 不该放弃的情况

| 信号 | 判断 | 建议 |
|------|------|------|
| 刚上线1周，数据不好看 | 太早下结论 | 至少跑2-4周 |
| 次留25-30%，不算差 | 有优化空间 | 继续迭代 |
| 被驳回1-2次 | 正常现象 | 改了再提 |
| 收入少但在增长 | 趋势向好 | 继续 |
| 自己觉得好玩，朋友也觉得好玩 | 产品有基础 | 可能是推广问题 |

### 决策框架

```
问自己这5个问题：
1. 如果今天从零开始，我还会做这个项目吗？
   - 不会 → 该放弃了（你只是舍不得沉没成本）

2. 数据上有没有任何一个正向信号？
   - 完全没有 → 大概率该放弃
   - 有（哪怕很小）→ 可以再试一轮

3. 我还能投入多少时间/钱？
   - 已经到极限了 → 不要借钱/辞职去赌

4. 失败的原因我清楚吗？
   - 不清楚 → 先搞清楚再决定（别稀里糊涂放弃）
   - 清楚且不可解决 → 放弃

5. 放弃后我有下一步计划吗？
   - 有 → 可以安心放弃
   - 没有 → 先想好下一步再放手
```

## 项目复盘模板

### 完整复盘6步（项目结束/放弃时做一次）

```
第1步：回顾假设
- 立项时的核心假设是什么？
  示例："消除+放置的混合玩法能吸引25-40岁女性用户"
- 预期目标是什么？
  示例："上线3个月DAU达到5000，月广告收入3000+"
- 这些假设当时为什么觉得成立？
  示例："看到XX游戏类似玩法月活百万"

第2步：看实际数据
- 实际达成了什么？
  示例："上线2个月，最高DAU 200，月收入最高150元"
- 关键指标实际值 vs 预期值：
  | 指标 | 预期 | 实际 | 差距 |
  |------|------|------|------|
  | 次留 | 35% | 22% | -13pp |
  | DAU | 5000 | 200 | -96% |
  | 月收入 | 3000 | 150 | -95% |

第3步：分析差距原因
- 为什么没达到？（不要只说"推广没做好"）
- 是产品问题？（玩法不够吸引/体验有硬伤）
- 是市场问题？（品类饱和/时机不对）
- 是执行问题？（开发太慢/质量不够）
- 是增长问题？（没人知道/不会推）
- 哪个是主因？（通常不是单一原因，但有主次）

第4步：如果重来
- 如果回到立项那天，我会怎么做？
- 哪些决策是对的？（保留）
- 哪些决策是错的？（避免）
- 哪些事情应该更早做？（前置）
- 哪些事情根本不该做？（砍掉）

第5步：提炼教训
- 用一句话总结最大的教训
  示例："不要在没有验证核心玩法的情况下做完整游戏"
- 提炼3条可复用的经验：
  1. [具体经验]
  2. [具体经验]
  3. [具体经验]
- 这些经验如何应用到下一个项目？

第6步：记录归档
- 把复盘写入文档/memory
- 保留有用的代码/资产（下个项目可能复用）
- 更新品类认知（这个品类的真实数据）
- 如果有数据，贡献到案例库
```

### 快速复盘（小项目/短周期）

```
3个问题，10分钟：
1. 什么有效？（下次继续）
2. 什么无效？（下次不做）
3. 下次第一个要改的是什么？（最重要的一个改变）
```

## 心理支持

### 失败不是终点，是学费

```
经验参考（行业经验估计，非统计数据）：
- 微信小游戏取得可观收益的比例约5-10%
- 大部分成功者之前都有1-3个失败项目
- 第一个游戏大概率不赚钱（这是正常的）
- 你在这个过程中学到的东西是有价值的

换个角度看：
- 你学会了：游戏设计/编程/合规/运营/数据分析（至少一部分）
- 你知道了：什么不work（这比不知道强100倍）
- 你有了：可复用的代码/资产/经验/认知
- 你验证了：一个假设（哪怕结果是"不成立"也是成果）

不要做的事：
- 不要因为一个项目失败就否定自己的能力
- 不要和别人"一夜爆火"的案例比（幸存者偏差）
- 不要在情绪低落时做"再也不做了"的决定
- 不要觉得"浪费了时间"（学习从来不是浪费）

可以做的事：
- 休息几天（真的，先休息）
- 找同行聊聊（独立开发者社区很多同路人）
- 把复盘做完（理性分析完会好受很多）
- 等情绪过了再决定下一步
```

### 常见心理陷阱

| 陷阱 | 表现 | 应对 |
|------|------|------|
| 沉没成本 | "已经投了6个月，不能白费" | 过去的投入已经沉没，决策只看未来 |
| 投机心态 | "再投一点就能回本" | 没有数据支持的投入就是投机 |
| 完美主义 | "再打磨一下就好了" | 上线才有数据，打磨不产生数据 |
| 比较焦虑 | "别人都成功了我为什么不行" | 你只看到了成功的（幸存者偏差） |
| 全有全无 | "要么爆款要么失败" | 月入几千也是正向反馈，也是学习 |

## 放弃后的下一步

### 标准路径

```
第1步：做完复盘（1-2天）
- 用上面的复盘模板
- 诚实面对数据
- 提炼可复用经验

第2步：休息（3-7天）
- 不碰游戏开发
- 做点别的（运动/社交/其他爱好）
- 让大脑从"项目模式"中出来

第3步：决定方向（1周）
选项A：换个品类/玩法继续做
  - 适合：技术能力OK，但方向选错了
  - 行动：用复盘教训选新品类，先做最小原型验证

选项B：换个平台/形式
  - 适合：微信小游戏这个形式不适合你的产品
  - 行动：考虑微信小游戏/App/Steam/其他平台

选项C：先学习再回来
  - 适合：感觉自己能力还不够
  - 行动：系统学习（引擎/设计/运营），3-6个月后再启动

选项D：彻底转方向
  - 适合：发现自己不适合/不喜欢做游戏
  - 行动：这完全OK。技能可迁移（编程/产品思维/数据分析）

第4步：提炼资产
- 代码：哪些模块可以复用？（UI框架/网络层/工具类）
- 美术：哪些素材可以复用？（图标/UI/音效）
- 认知：对品类/用户/市场的理解
- 人脉：开发过程中认识的人
- 数据：失败项目的数据也是有价值的参考

第5步：启动下一个（如果选A/B）
- 不要从零开始（复用上一个项目的框架）
- 第一个月只做核心玩法原型
- 用最小成本验证（不要一上来就做完整游戏）
- 设一个"止损线"（比如：2个月内次留达不到25%就换方向）
```

### 从失败到成功的典型路径

```
项目1（失败）：
- 做了个消除游戏，次留18%，DAU从未超过50
- 教训：纯消除太同质化，没有差异化

项目2（半成功）：
- 消除+剧情，次留32%，DAU 2000，月入3000
- 教训：差异化有效，但量不够

项目3（成功）：
- 基于项目2的经验，换了个更大众的题材
- 次留38%，DAU 5万，月入8万
- 关键：前两个项目的积累全部用上了

时间线：项目1→项目3 通常12-18个月
```
