# 审核提交流程模块

> 微信小游戏从开发完成到正式上线的完整提审SOP，覆盖提审前检查、操作流程、资料准备、审核周期、发布操作、变现开通全流程。

## 一、提审前完整检查清单

## 二、提审操作路径

### 2.1 完整操作路径

```
微信公众平台 (mp.weixin.qq.com)
  → 登录（管理员扫码）
  → 左侧菜单「管理」
  → 「版本管理」
  → 「开发版本」区域
  → 找到目标版本
  → 点击「提交审核」
  → 填写审核信息
  → 确认提交
```

### 2.2 前置操作（提审前必做）

```
Step 1: 上传代码
  微信开发者工具 → 工具栏「上传」→ 填写版本号和备注 → 上传

Step 2: 设置体验版（强烈建议）
  公众平台 → 版本管理 → 开发版本 → 选为体验版
  → 添加体验成员（最多100人）
  → 体验版测试通过后再提审

Step 3: 提交审核
  版本管理 → 开发版本 → 提交审核
```

### 2.3 注意事项

| 注意点 | 说明 |
|--------|------|
| 上传频率 | 无限制，但审核有频率限制 |
| 版本命名 | 建议语义化：1.0.0 / 1.1.0 / 2.0.0 |
| 体验版 | 提审前务必先设体验版测试 |
| 审核时段 | 工作日提交，避免周五下午/节假日前 |
| 多次驳回 | 连续驳回3次+，建议暂停排查 |

| 游戏截图 | ≥3张 | 真实游戏画面，非设计稿 |
| 游戏录屏 | ≤3分钟（可选但建议） | 完整演示核心玩法 |

| 测试账号 | 如需登录测试 | 提供可用测试账号 |

| 游戏类型 | 推荐类目 | 所需资质 |
|---------|---------|---------|
| 消除/三消 | 休闲游戏→消除 | 无（建议软著） |
| 跑酷/动作 | 休闲游戏→动作 | 无（建议软著） |

### 3.3 资质文件清单

| 资质 | 适用场景 | 办理周期 | 办理渠道 |
|------|---------|---------|---------|

| 游戏版号 | 含内购（必须） | 3-6个月+ | 游戏出版主管部门 |

| 营业执照 | 企业主体 | - | 市场监管局 |
| 文网文 | 部分类目 | 1-2个月 | 文旅部门 |

## 四、游戏截图要求

### 4.1 基本规格

| 属性 | 要求 |
|------|------|
| 数量 | ≥ 3张（建议5张） |
| 格式 | PNG / JPG |
| 尺寸 | 与游戏实际分辨率一致 |
| 大小 | 单张 ≤ 10MB |
| 内容 | 真实游戏运行画面 |

### 4.2 截图内容建议（5张方案）

| 序号 | 内容 | 目的 |
|------|------|------|
| 1 | 游戏主界面 | 展示整体风格 |
| 2 | 核心玩法画面 | 展示怎么玩 |
| 3 | 游戏进行中（精彩瞬间） | 展示趣味性 |
| 4 | 特色功能/关卡 | 展示差异化 |
| 5 | 社交/排行/成就 | 展示深度 |

### 4.3 截图禁忌

```markdown
### 截图不可出现：
- ❌ 设计稿/概念图（必须是真实运行画面）
- ❌ 其他游戏的画面
- ❌ 与实际游戏不符的美化图
- ❌ 包含手机状态栏/系统UI
- ❌ 包含违规内容
- ❌ 纯文字/纯色图
- ❌ 模糊/低质量截图
- ❌ 包含"测试""demo"等字样
```

## 五、游戏录屏要求

### 5.1 基本规格

| 属性 | 要求 |
|------|------|
| 时长 | ≤ 3分钟 |
| 格式 | MP4 |
| 大小 | ≤ 100MB |
| 内容 | 完整演示核心玩法 |

### 5.2 录屏内容建议（2分钟方案）

| 时间段 | 内容 | 要点 |
|--------|------|------|
| 0:00-0:15 | 启动→主界面 | 展示加载速度和首屏 |
| 0:15-0:30 | 开始游戏→新手引导 | 展示上手体验 |
| 0:30-1:30 | 核心玩法完整演示 | 展示趣味性和操作 |
| 1:30-1:50 | 结算→分享/排行 | 展示社交功能 |
| 1:50-2:00 | 特色功能展示 | 展示差异化 |

### 5.3 录屏注意事项

```markdown
### 录屏要求：
- ✅ 真机录制（非模拟器）
- ✅ 横屏/竖屏与实际游戏一致
- ✅ 操作流畅，展示真实体验
- ✅ 包含声音（BGM+音效）
- ✅ 画面清晰（≥720p）

### 录屏禁忌：
- ❌ 加速/慢放（需真实速度）
- ❌ 剪辑拼接（一镜到底为宜）
- ❌ 后期加特效/字幕
- ❌ 展示未实现的功能
- ❌ 包含违规内容
```

## 七、审核周期

### 7.1 正常审核时间

| 场景 | 审核时长 | 说明 |
|------|---------|------|
| 首次提审 | 1-7个工作日（多数1-3天） | 首次审核更严格 |
| 版本更新 | 2-4小时（快）/ 1-2天（常规） | 小更新可能走快速通道 |
| 高峰期 | 可能1周+ | 春节前/国庆前/暑假 |
| 被驳回后重审 | 1-2个工作日 | 与首次类似 |

### 7.2 影响审核速度的因素

| 因素 | 影响 |
|------|------|
| 提交时间 | 工作日上午提交最快 |
| 游戏复杂度 | 简单休闲 < 复杂RPG |
| 历史记录 | 无违规记录更快 |
| 类目 | 特殊类目（棋牌）更慢 |
| 是否含内购 | 含内购审核更严格 |
| 节假日 | 法定节假日不审核 |

### 7.3 审核状态跟踪

```
公众平台 → 版本管理 → 审核版本

状态说明：
- 审核中：等待审核（不可撤回后重新提交，需等审核完成）
- 审核通过：可发布
- 审核驳回：查看原因→修复→重新提审
```

### 7.4 加急审核

| 条件 | 说明 |
|------|------|
| 适用场景 | 紧急Bug修复、安全漏洞 |
| 申请方式 | 提审时选择"加急审核"（有次数限制） |
| 审核时长 | 通常2-4小时 |
| 限制 | 每个小程序/小游戏每月有限次数 |
| 注意 | 非紧急不要滥用，影响信用 |

## 八、体验版设置

### 8.1 设置路径

```
公众平台 → 版本管理 → 开发版本 → 选为体验版
```

### 8.2 体验版 vs 开发版 vs 正式版

| 属性 | 开发版 | 体验版 | 正式版 |
|------|--------|--------|--------|
| 访问方式 | 开发者工具预览 | 体验版二维码 | 微信搜索/分享 |
| 可访问人数 | 开发者本人 | ≤100人（可配置） | 所有用户 |
| 需要审核 | 否 | 否 | 是 |
| 用途 | 开发调试 | 内测/验收 | 正式上线 |
| 数据 | 独立 | 独立 | 正式环境 |

### 8.3 体验版测试流程

```markdown
### 体验版测试SOP（提审前必做）

Step 1: 设置体验版
  - 上传最新代码到开发版本
  - 选为体验版
  - 添加测试成员（至少3人）

Step 2: 分发测试
  - 分享体验版二维码给测试人员
  - 要求覆盖Android+iOS
  - 要求覆盖不同微信版本

Step 3: 测试内容
  - 完整走一遍核心流程
  - 重点测试真机场景（见qa.md）
  - 记录所有问题

Step 4: 确认
  - 所有P0/P1问题已修复
  - 测试人员确认"可以提审"
  - 进入正式提审流程
```

## 九、审核通过后的发布操作

### 9.1 发布路径

```
公众平台 → 版本管理 → 审核版本（已通过）
  → 点击「发布」
  → 确认发布
  → 上线成功
```

### 9.2 发布前确认

| # | 确认项 | 说明 |
|---|--------|------|
| 1 | 服务器就绪 | 后端服务稳定运行 |
| 2 | 广告位配置 | 广告组件已创建并配置 |
| 3 | 数据监控 | 埋点/监控已部署 |
| 4 | 客服准备 | 反馈渠道畅通 |
| 5 | 运营物料 | 分享图/推广素材就绪 |
| 6 | 发布时间 | 避开凌晨，建议上午10点 |

### 9.3 发布后验证

```markdown
### 上线后30分钟内必做：
- [ ] 微信搜索游戏名称→可找到
- [ ] 点击进入→正常加载
- [ ] 完整玩一局→无异常
- [ ] 检查广告展示→正常
- [ ] 检查数据上报→后台有数据
- [ ] 分享给好友→可正常打开
- [ ] 查看公众平台→无异常告警
```

### 9.4 灰度发布（可选）

| 属性 | 说明 |
|------|------|
| 功能 | 按比例逐步放量 |
| 路径 | 发布时选择"分阶段发布" |

## 十、流量主开通条件和流程

### 10.1 开通条件

| 条件 | 要求 | 说明 |
|------|------|------|
| 累计独立访客(UV) | > 500 | 历史累计，非单日（以微信广告官方最新门槛为准） |
| 账号状态 | 正常 | 无刷粉行为、无严重违规记录 |
| 主体类型 | 企业/个体工商户（个人主体不可开通流量主） | - |
| 内容合规 | 无违规记录 | 近期无处罚 |

### 10.2 开通流程

```
Step 1: 确认UV达标
  公众平台 → 统计 → 访问分析 → 确认累计UV > 500（以最新官方门槛为准）

Step 2: 申请开通
  公众平台 → 推广 → 流量主 → 开通
  → 阅读并同意协议
  → 填写结算信息（银行卡/对公账户）

Step 3: 创建广告位
  流量主 → 广告位管理 → 新建广告位
  → 选择广告类型（Banner/插屏/激励视频/格子）
  → 获取广告位ID

Step 4: 代码接入
  在游戏代码中接入广告组件
  → 使用广告位ID
  → 测试广告展示

Step 5: 上线验证
  → 发布新版本
  → 确认广告正常展示和计费
```

### 10.3 广告类型及收益

| 广告类型 | eCPM参考 | 适用场景 | 用户体验影响 |
|---------|---------|---------|-------------|
| 激励视频 | 40-120元 | 复活/加倍/解锁 | 低（用户主动） |
| 插屏广告 | 15-40元 | 关卡间/暂停 | 中 |
| Banner | 3-10元 | 页面底部 | 低（但收益低） |
| 格子广告 | 5-15元 | 结算页/商城 | 低 |

### 10.4 结算说明

| 属性 | 说明 |
|------|------|
| 结算周期 | 月结（次月结算上月） |
| 起结金额 | 100元 |
| 到账时间 | 申请后3-7个工作日 |
| 税务 | 个人代扣个税，企业开票 |

## 十一、内购开通条件（企业主体）

### 11.1 开通条件

| 条件 | 要求 | 说明 |
|------|------|------|
| 主体类型 | 企业（必须） | 个人主体不可开通内购 |
| 游戏版号 | 必须 | 游戏出版主管部门颁发 |
| 营业执照 | 经营范围含游戏 | - |
| 软著 | 建议有 | - |
| 微信认证 | 已认证（300元/年） | - |
| 商户号 | 微信支付商户号 | 需单独申请 |

### 11.2 开通流程

```
Step 1: 准备资质
  - 营业执照（经营范围含游戏/软件）
  - 游戏版号（必须）
  - 软件著作权（建议）
  - 法人身份证

Step 2: 微信认证
  公众平台 → 设置 → 微信认证 → 完成认证（300元）

Step 3: 开通微信支付商户号
  pay.weixin.qq.com → 注册 → 提交资质 → 审核（1-5天）

Step 4: 绑定商户号
  公众平台 → 微信支付 → 关联商户号

Step 5: 配置虚拟支付
  公众平台 → 功能 → 虚拟支付 → 开通
  → 配置商品（名称/价格/描述）

Step 6: 代码接入
  → 接入微信支付API
  → 实现下单/支付/回调/发货逻辑
  → 测试支付全流程

Step 7: 提审
  → 版本说明中注明"新增内购功能"
  → 确保版号信息已填写
```

### 11.3 内购合规要求

```markdown
### 内购红线：
- ❌ 无版号不可收费（任何形式）
- ❌ iOS不可使用微信虚拟支付以外的渠道（不可引导到外部支付）
- ❌ 不可引导未成年人不当消费
- ❌ 不可虚假标价/虚假折扣
- ❌ 随机付费（随机抽取）必须公示概率
- ❌ 不可强制消费才能体验核心玩法

### 内购规范：
- ✅ 明码标价
- ✅ 支付前二次确认
- ✅ 提供消费记录查询
- ✅ 未成年人消费限制
- ✅ 退款渠道畅通
- ✅ 概率公示（如有随机机制）
```
