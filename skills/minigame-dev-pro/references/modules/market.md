# 市场情报引擎 (Market Intelligence)

## 设计原则

- 诚实第一。不画饼，不夸大。如果某个品类已经卷到个人开发者没机会，直接说。
- 数据必须标注来源和可信度。没有数据支撑的判断标注为"经验推断"。
- 给建议时永远附带"为什么推荐"和"为什么不推荐其他"，让用户理解逻辑。
- 变现预期给区间，不给单点数字。永远说"最好情况/中位情况/最差情况"。

## 市场分析四维度

### 维度1：时间窗口分析

**分析什么：** 当前时间点适合做什么品类，有什么节日/热点可以利用。

**具体操作：**

1. 查看微信小游戏当前热门榜单：
   - 打开微信 → 发现 → 小程序 → 搜索"小游戏" → 查看"热门"标签
   - 记录Top20游戏的品类分布

2. 查看即将到来的节日/热点窗口（见下方"节日窗口期倒推"）

3. 判断当前市场热度周期：
   - 某品类连续3个月有新爆款出现 → 上升期
   - 某品类头部产品稳定但无新爆款 → 稳定期（红海）
   - 某品类头部产品DAU持续下滑 → 下降期（别碰）

**输出格式：**
```
时间窗口分析（2026年1月）：
- 春节窗口（1月28日-2月4日）：休闲/社交/棋牌类流量高峰，现在做来得及
- 情人节（2月14日）：合成/装扮类小窗口
- 开学季（2月底）：益智/教育类小窗口
- 当前上升品类：合成类（连续2个月有新品进Top50）
- 当前红海品类：消除类（头部固化，新品难进Top100）
- 当前下降品类：跳跃闯关类（已过气，别碰）
```

### 维度3：竞争分析

**分析什么：** 目标品类的头部产品是谁，它们的弱点在哪，你能切入什么缝隙。

**竞争分析方法（头部产品弱点挖掘）：**

#### Step 1: 确定分析对象

- 打开微信 → 搜索目标品类关键词（如"合成""消除"）
- 记录排名前10的游戏
- 重点分析前3名（它们定义了品类标准）

#### Step 2: 体验拆解（每个产品花30分钟玩）

记录以下维度：
```
产品名：XXX
核心循环：[一句话描述，如"合成水果→得分→解锁新水果"]
首次体验：[前3分钟的感受，哪里卡住了]
广告频率：[每X分钟弹一次广告，什么形式]
付费点：[有没有内购，卖什么]
社交机制：[有没有排行榜/分享/对战]
明显缺点：[玩的时候哪里让你不爽]
用户评价：[去小程序评论区看差评，记录高频抱怨]
```

#### Step 3: 弱点归纳

常见头部产品弱点模式：
- "广告太多太频繁" → 你的机会：减少广告频率，用更精准的广告位设计提高单次收入
- "后期内容不足/重复" → 你的机会：设计更深的成长线
- "社交功能弱" → 你的机会：加入好友对战/排行（注意合规）
- "美术风格老旧" → 你的机会：用更新的视觉风格（如3D卡通、像素复古）
- "新手引导太长/太复杂" → 你的机会：3秒上手，0文字引导
- "没有持续更新" → 你的机会：每周更新内容，保持新鲜感

#### Step 4: 差异化定位

```
差异化公式：
  你的游戏 = 头部产品的核心玩法 + 头部产品的弱点修复 + 一个独特卖点

示例：
  头部：合成大西瓜（合成+物理引擎）
  弱点：后期无聊、没有社交
  你的："合成星球"（合成+物理引擎+好友PK+每周新星球）
  独特卖点：好友实时对战合成（你合成你的，他合成他的，比谁先合出最大星球）
```

### 维度4：变现分析

**分析什么：** 这个品类/这款游戏能赚多少钱，天花板在哪。

**变现天花板诚实告知（必须执行）：**

每次给出变现预期时，必须同时给出三档：

```
变现预期（合成类休闲游戏，个人开发者，零推广预算）：

最好情况（Top 5%）：
  DAU 5万+，eCPM 80元，日广告收入 4000元+，月收入 12万+
  前提：被微信推荐/自然传播爆发/踩中热点
  概率：约5%

中位情况（中位数）：
  DAU 2000-5000，eCPM 50元，日广告收入 100-250元，月收入 3000-7500元
  前提：正常运营，有基础分享裂变
  概率：约40%

最差情况（Bottom 30%）：
  DAU < 500，eCPM 30元，日广告收入 < 15元，月收入 < 450元
  前提：没有推广、分享率低、留存差
  概率：约30%

⚠️ 诚实说明：
  - 2026年微信小游戏市场，个人开发者零推广、首款游戏即月入过万的占比极低（行业经验估计，非统计数据）
  - 大多数个人开发者的第一款游戏月收入在500-3000元区间
  - 这不是劝退，是让你有正确预期。第一款游戏的核心目标是"跑通流程+积累数据"
  - 真正赚钱的开发者通常是第3-5款游戏开始盈利
  - 以上均为参考区间与经验判断，不构成收益承诺，需以实际运营数据为准
```

**变现模式对比：**

| 变现模式 | 适用条件 | 收入天花板 | 用户体验影响 | 合规要求 |
|----------|----------|-----------|-------------|----------|
| 激励视频广告 | 所有游戏 | 中（eCPM 40-100） | 低（用户主动看） | 无特殊 |
| 插屏广告 | 休闲/超休闲 | 低（eCPM 20-50） | 高（打断体验） | 频率限制 |
| Banner广告 | 所有游戏 | 极低（eCPM 5-15） | 中（占屏幕） | 位置限制 |
| 内购（道具/皮肤） | 企业主体+版号 | 高（无上限） | 低 | 版号+米大师 |
| 混合变现 | 企业主体 | 最高 | 中 | 版号（如有内购） |

## 品类推荐逻辑

### 推荐决策树

```
输入：用户画像（identity, tech_level, budget, time, 个人偏好）

Q1: 你的身份？
  ├─ 个人 → 排除：棋牌（需版号）、重度策略（工作量太大）
  └─ 企业 → 全部可选

Q2: 你的技术水平？
  ├─ developer → 全部可选
  ├─ semi_technical → 排除：需要复杂物理引擎的（如弹球、赛车）
  └─ non_technical → 只推荐：文字/知识类、简单合成类、模板可改的品类

Q3: 你的时间？
  ├─ fulltime → 全部可选
  ├─ parttime → 排除：模拟经营（内容量太大）、MMO社交（需持续运营）
  └─ hobby → 只推荐：超休闲（单局<1分钟）、益智（关卡制，可慢慢做）

Q4: 你的预算？
  ├─ zero → 排除：需要大量美术素材的（模拟经营、换装）
  ├─ low → 排除：需要高质量3D美术的
  └─ mid/high → 全部可选

Q5: 你有没有特别想做的类型？
  ├─ 有 → 检查是否与Q1-Q4冲突，不冲突则推荐该品类+差异化方向
  └─ 没有 → 按"竞争强度低 × 变现能力高 × 匹配你的条件"排序推荐Top3
```

### 推荐输出格式

```
基于你的条件（个人/会Cocos/兼职/零预算），我推荐以下3个品类：

🥇 首选：合成类
   为什么：开发量适中（20-30天）、不需要复杂美术、广告变现效果好、
          当前市场仍有空间（不像消除类已经卷死）
   参考产品：合成大西瓜、合成星球
   你的切入点：[基于竞争分析给出的具体差异化方向]
   预期开发时间：25天（兼职x1.8 = 45天）
   变现预期：中位月入3000-5000元

🥈 次选：益智/解谜类
   为什么：关卡制可以慢慢做、不需要服务器、留存好（每天来解一关）
   参考产品：脑筋急转弯、成语小秀才
   你的切入点：[具体方向]
   预期开发时间：30天（兼职x1.8 = 54天）
   变现预期：中位月入2000-4000元

🥉 备选：放置/挂机类
   为什么：用户粘性高（每天回来看收益）、后期可以加深度
   参考产品：寻道大千（放置修仙）、咸鱼之王（挂机放置）
   你的切入点：做轻度放置，不要做重度
   预期开发时间：35天（兼职x1.8 = 63天）
   变现预期：中位月入2500-4500元

❌ 不推荐你做的：
   - 消除类：红海，头部产品（开心消消乐）用户心智已固化，新品极难出头
   - 模拟经营：零预算做不出足够内容量，半成品没人玩
   - 棋牌类：个人主体无法申请版号，合规路走不通
```

### 倒推计算逻辑

```
最晚完成开发日期 = 节日日期 - 提审时间(5天) - 软启动(3天) - 缓冲(7天)

示例：目标春节（1月28日）
  最晚提审日期 = 1月28日 - 3天(软启动) - 7天(缓冲) = 1月18日
  最晚完成开发 = 1月18日 - 5天(提审) = 1月13日
  如果今天已经是12月20日 → 剩余24天 → 只够做超休闲（开发<15天）
  如果今天已经是1月5日 → 来不及了 → 建议瞄准下一个窗口（情人节）
```

### 热点追踪（非节日类）

- 每周检查：微博热搜、抖音热榜、微信指数（index.weixin.qq.com）
- 判断标准：某话题连续3天在热搜 → 判断是否可做游戏化
- 响应速度：热点类小游戏从创意到上架不超过7天才有意义
- 示例：某综艺节目火了 → 做该节目相关的答题/模拟游戏 → 7天内上架蹭热度

### 数据来源分级

| 可信度 | 来源类型 | 示例 | 标注方式 |

| A级（高） | 官方公布数据 | 微信公开课数据、微信广告官方eCPM | [数据来源：微信官方，2025Q4] |
| B级（中高） | 行业报告 | 伽马数据、QuestMobile、艾瑞咨询 | [数据来源：伽马数据2025年报，可能有统计口径偏差] |

| D级（低） | 经验推断 | 基于品类规律的合理推测 | [经验推断，无直接数据支撑，仅供参考] |

### 标注规则

- 每个数据点必须标注来源等级
- 没有数据支撑的判断必须标注"经验推断"
- 收入数据永远给区间，不给单点
- 涉及"市场规模""用户量"等大数字时，注明统计口径（DAU/MAU/累计注册）
- 超过6个月的数据标注"可能已过时"

### 示例

```
合成类品类eCPM约40-80元/千次展示。
[数据来源：微信广告2025年Q3官方公布数据(A级) + 开发者社区反馈(C级)交叉验证]

2026年合成类预计仍有增长空间。
[经验推断(D级)：基于2024-2025年连续有新品进入Top50的趋势外推，
 但市场变化快，不构成确定性判断]
```

## 趋势判断框架

### 三态判断：上升 / 稳定 / 下降

**判断依据（按权重排序）：**

1. **新品表现（权重40%）：** 最近3个月，该品类有没有新品进入微信小游戏Top100？
   - 有2款以上新品进入 → 上升信号
   - 无新品进入，但头部稳定 → 稳定信号
   - 头部产品排名持续下滑 → 下降信号

2. **搜索热度（权重25%）：** 微信指数（index.weixin.qq.com）中品类关键词的趋势
   - 搜索量环比增长>20% → 上升
   - 搜索量波动<10% → 稳定
   - 搜索量环比下降>20% → 下降

3. **头部产品状态（权重20%）：** Top3产品的更新频率和用户评价
   - 频繁更新+好评 → 品类健康（上升/稳定）
   - 停止更新+差评增多 → 品类衰退（下降）

4. **开发者涌入/退出（权重15%）：** 开发者社区讨论热度
   - 大量开发者讨论"怎么做XX类" → 上升（但也意味着即将变卷）
   - 讨论减少 → 稳定/下降

### 输出格式

```
品类趋势判断：合成类
判断结果：📈 上升期（但接近峰值）
置信度：中高（B-C级数据支撑）

依据：
1. 新品表现：最近3个月有3款合成类新品进入Top100 ✅ 上升信号
2. 搜索热度：微信指数"合成游戏"环比+15% ✅ 上升信号
3. 头部状态：物理合成品类头部产品仍在更新，评分4.5 ✅ 健康
4. 开发者热度：社区讨论增多 ⚠️ 上升但预示竞争加剧

建议：
- 现在进入仍有机会，但窗口期约6-12个月
- 必须有明确差异化，不能做"又一个同质化合成游戏"
- 如果6个月后才开始做，建议重新评估（可能已进入红海）
```

### 趋势判断的诚实边界

必须告知用户：
- 趋势判断不是预测，是基于当前数据的推断
- 微信小游戏的爆款有极大偶然性（同类事件无法预测，如"羊了个羊"（2022年现象级小游戏））
- 品类趋势好 ≠ 你的游戏一定成功（执行质量才是关键）
- 建议用户不要all-in单一品类判断，保持灵活
