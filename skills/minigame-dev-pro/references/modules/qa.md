# 质量保障与测试模块

> 微信小游戏上线前质量保障的完整SOP，覆盖四层测试体系、性能标准、兼容性矩阵、真机场景、模拟审核全流程。

---

## 一、四层测试体系

### 测试金字塔（由内到外）

```
第1层：开发者自检（每次构建后）
    ↓ 通过
第2层：专家团审查（里程碑节点）
    ↓ 通过
第3层：模拟审核（提审前）
    ↓ 通过
第4层：真机测试（提审前最终确认）
    ↓ 通过
→ 提交微信审核
```

### 第1层：开发者自检

| 检查维度 | 频率 | 工具 | 通过标准 |
|---------|------|------|---------|
| 功能完整性 | 每次构建 | 手动+自动化 | 核心流程无阻断性Bug |
| 性能指标 | 每次构建 | 微信开发者工具 | 满足性能基线 |
| 资源加载 | 每次构建 | Network面板 | 无404/超时 |
| 控制台报错 | 每次构建 | Console面板 | 0 Error |
| 代码规范 | 每次提交 | ESLint | 0 Error |

### 第2层：专家团审查

- 触发时机：策划完成、开发完成、提审前、被驳回后
- 详细流程见 `references/modules/review.md`
- 输出：评分 + 分级问题清单

### 第3层：模拟审核

- 触发时机：专家团审查通过后、真机测试前
- 模拟微信AI审核 + 人工审核双重视角
- 详细流程见本文第五节

### 第4层：真机测试

- 触发时机：模拟审核通过后
- 覆盖主流机型 + 极端场景
- 详细清单见本文第四节

## 三、性能测试标准

### 3.1 硬性指标（必须达标）

| 指标 | 标准 | 测量方法 | 不达标后果 |
|------|------|---------|-----------|
| 首屏加载时间 | ≤ 3秒 | 从点击到可交互 | 用户流失率>50% |
| 运行帧率 | ≥ 30fps（目标60fps） | 真机Performance面板 | 体验差，审核可能驳回 |
| 内存占用 | ≤ 256MB（低端机≤200MB） | wx.getPerformance() | 低端机崩溃 |
| 包体大小 | 主包 ≤ 4MB | 构建产物检查 | 无法上传 |
| 总包大小 | ≤ 30MB（含分包） | 构建产物检查 | 无法上传 |
| 单帧耗时 | ≤ 33ms（30fps） | Profiler | 卡顿 |
| 启动白屏 | ≤ 1秒 | 真机录屏计时 | 体验差 |

### 3.2 性能优化检查项

```markdown
### 加载性能
- [ ] 首包 ≤ 4MB（代码+必要资源）
- [ ] 使用分包加载（按关卡/场景拆分）
- [ ] 图片资源已压缩（TinyPNG/Sharp）
- [ ] 音频使用适当格式和码率
- [ ] 使用CDN加载远程资源
- [ ] 预加载策略：下一关资源提前加载
- [ ] 加载进度条真实反映进度

### 渲染性能
- [ ] DrawCall ≤ 50（复杂场景 ≤ 100）
- [ ] 图集合并（TexturePacker）
- [ ] 避免每帧创建对象（对象池）
- [ ] 离屏元素不渲染（视口裁剪）
- [ ] 粒子数量控制（≤ 200个/屏）
- [ ] 避免频繁GC（减少临时对象）

### 内存管理
- [ ] 场景切换时释放旧资源
- [ ] 纹理尺寸合理（≤ 2048x2048）
- [ ] 音频及时释放
- [ ] 无内存泄漏（反复进出场景测试）
- [ ] 低端机降级策略（减少特效）
```

### 3.3 性能测试执行方法

| 工具 | 用途 | 操作路径 |
|------|------|---------|
| 微信开发者工具-Audits | 综合性能评分 | 工具栏→Audits→运行 |
| 微信开发者工具-Performance | 帧率/内存/CPU | 调试器→Performance |
| 真机调试-Performance | 真实环境性能 | 预览→vConsole→Performance |
| wx.getPerformance() | 运行时内存监控 | 代码埋点 |
| 微信小游戏性能面板 | 线上监控 | 公众平台→开发→性能监控 |

## 七、审核通过率预估模型

### 7.1 评分模型

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 功能完整性 | 25% | 无Bug=10, 轻微Bug=7, 阻断Bug=0 |
| 性能达标 | 20% | 全部达标=10, 1项不达标=5, 多项=0 |
| 内容合规 | 25% | 完全合规=10, 轻微风险=5, 明确违规=0 |
| 用户体验 | 15% | 流畅自然=10, 有小瑕疵=7, 体验差=3 |
| 资料完整 | 15% | 截图/描述/资质齐全=10, 缺项=5 |

### 7.2 通过率对照

| 综合得分 | 预估通过率 | 建议 |
|---------|-----------|------|
| 90-100 | 95%+ | 可直接提审 |
| 80-89 | 85% | 建议修复后提审 |
| 70-79 | 60% | 必须修复再提审 |
| 60-69 | 30% | 重大修改后重新评估 |
| <60 | <10% | 不建议提审，全面整改 |

### 7.3 加分/减分项

**加分项：**
- 有软著证书（+5%）
- 有版号（+10%，含内购必须）
- 历史审核记录良好（+5%）
- 类目选择精准（+3%）

**减分项：**
- 首次提审（-5%，审核更严格）
- 近期有违规记录（-15%）
- 类目与内容不完全匹配（-10%）
- 截图与实际不符（-20%，可能直接驳回）

## 八、常见驳回原因Top10及预防措施

| 排名 | 驳回原因 | 占比 | 预防措施 |
|------|---------|------|---------|
| 1 | 游戏存在Bug/闪退 | ~20% | 四层测试体系全覆盖，真机测试≥5款机型 |
| 2 | 广告影响体验（遮挡/强制） | ~15% | 广告不遮挡核心操作，可关闭，激励视频用户主动触发 |
| 3 | 类目选择不正确 | ~12% | 仔细对照微信类目定义，选择最精确的子类目 |
| 4 | 缺少隐私协议/授权不合理 | ~10% | 接入隐私协议组件，最小化权限申请 |
| 5 | 违规分享/强制关注 | ~10% | 分享仅用户主动触发，不绑定任何游戏内奖励，不强制关注 |
| 6 | 截图/描述与实际不符 | ~8% | 截图使用真实游戏画面，描述准确 |
| 7 | 内容违规（违反平台规范） | ~8% | 合规审查前置，小林专家专项审核 |
| 8 | 缺少版号/资质（内购类） | ~7% | 内购必须有版号，提前办理 |
| 9 | 防沉迷未接入 | ~5% | 接入微信防沉迷能力，未成年人限时 |
| 10 | 功能不完整/半成品感 | ~5% | 确保所有展示的功能都可用，无"敬请期待" |

### 驳回后处理SOP

```
收到驳回通知
  ↓
1. 仔细阅读驳回原因（公众平台→版本管理→审核记录）
  ↓
2. 定位问题（对应到具体功能/页面/资源）
  ↓
3. 触发专家审查（C合规 + 对应领域专家）
  ↓
4. 修复问题
  ↓
5. 重新执行四层测试（至少第1+4层）
  ↓
6. 更新版本说明（说明修复内容）
  ↓
7. 重新提审
  ↓
注意：连续驳回3次以上，暂停提审，全面排查
```

### 9.1 官方工具

| 工具 | 用途 | 获取方式 |
|------|------|---------|
| 微信开发者工具 | 开发调试/性能分析/上传 | 微信官方下载 |
| 真机调试 | 真实环境调试 | 开发者工具→预览/真机调试 |
| 公众平台-性能监控 | 线上性能数据 | mp.weixin.qq.com |
| 公众平台-体验版 | 内测分发 | 版本管理→体验版 |
| Audits面板 | 性能/体验评分 | 开发者工具内置 |

### 9.2 第三方工具

| 工具 | 用途 | 备注 |
|------|------|------|
| Cocos Creator Profiler | 渲染性能分析 | Cocos引擎内置 |
| TexturePacker | 图集打包/优化 | 减少DrawCall |
| TinyPNG / Sharp | 图片压缩 | 减小包体 |
| Charles / Fiddler | 网络请求分析 | 调试接口/资源加载 |
| PerfDog | 移动端性能测试 | 帧率/CPU/内存 |
| 云真机平台（WeTest） | 多机型兼容测试 | 腾讯官方 |

### 9.3 自动化测试

| 方案 | 适用场景 | 说明 |
|------|---------|------|
| miniprogram-automator | 小游戏UI自动化 | 微信官方SDK |
| 自定义测试脚本 | 核心逻辑验证 | 单元测试框架 |
| CI/CD集成 | 每次构建自动检查 | 包体大小/代码规范 |

## 十、质量门禁（Quality Gate）

### 提审前必须满足：

```markdown
### 质量门禁检查表（全部✅才可提审）

**功能门禁**
- [ ] 核心流程0个P0/P1 Bug
- [ ] 功能测试清单100%通过
- [ ] 异常场景测试通过

**性能门禁**
- [ ] 首屏加载 ≤ 3秒（中端机实测）
- [ ] 运行帧率 ≥ 30fps（低端机实测）
- [ ] 内存峰值 ≤ 256MB（低端机≤200MB）
- [ ] 主包 ≤ 4MB

**兼容门禁**
- [ ] Android Top5机型通过
- [ ] iOS 2款机型通过
- [ ] 鸿蒙 1款机型通过（如有鸿蒙用户）

**合规门禁**
- [ ] 模拟审核通过（AI+人工）
- [ ] 专家团审查通过（全员）
- [ ] 隐私协议/防沉迷确认

**资料门禁**
- [ ] 截图≥3张（真实画面）
- [ ] 版本说明已填写
- [ ] 类目选择正确
- [ ] 资质文件齐全（如需要）
```
