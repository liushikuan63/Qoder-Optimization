# 美术与音频指导

> 面向个人开发者和小团队的美术音频实用指南，兼顾品质与成本。

---

## 1. 各品类推荐美术风格

### 1.1 风格匹配表
| 游戏品类 | 推荐风格 | 参考案例 | 制作难度 | 成本参考 |
|---------|---------|---------|---------|---------|
| 消除类 | 扁平卡通、糖果色 | 主流三消产品（糖果色Q版） | 低-中 | 低 |
| 放置/挂机 | 像素风、Q版 | 像素放置类产品、挂机点击类产品 | 低 | 极低 |
| 模拟经营 | 等距视角、温馨手绘 | 农场/小镇模拟类产品 | 中-高 | 中 |
| 卡牌/收集 | 立绘半写实、日系 | 日系卡牌收集类产品 | 高 | 高 |
| 跑酷/动作 | 简洁动感、剪影 | 轻量跑酷类产品、剪影风跑酷产品 | 中 | 中 |
| 答题/文字 | 极简扁平、图标化 | 答题竞技类产品 | 低 | 极低 |
| 塔防 | Q版卡通、明快 | 经典Q版塔防产品 | 中 | 中 |
| 合成类 | 圆润可爱、马卡龙色 | 物理合成类产品 | 低 | 低 |

### 1.2 风格选择原则
- **个人开发者**：选择制作难度低的风格（扁平/像素/极简）
- **小团队**：可以挑战Q版卡通/等距视角
- **有美术资源**：根据品类选择合适表现力风格
- **核心原则**：风格统一 > 单张精美。10张风格统一的图 > 1张精美+9张凑合

### 1.3 配色建议
| 品类 | 主色调 | 辅助色 | 避免 |
|------|--------|--------|------|
| 消除 | 高饱和糖果色 | 白色/浅色背景 | 暗沉、灰调 |
| 放置 | 柔和暖色/像素限定色 | 深色背景 | 过于刺眼 |
| 模拟 | 暖黄/草绿/天蓝 | 木色/米色 | 冷色调、工业感 |
| 跑酷 | 对比色（蓝+橙） | 渐变背景 | 单调、无层次 |
| 答题 | 蓝/绿（信任感） | 白色 | 花哨、分散注意力 |

## 2. 图标规范

### 2.1 微信小游戏图标要求
| 项目 | 要求 |
|------|------|
| 尺寸 | 方形PNG，建议512×512以上（后台展示约144×144，系统自动裁切） |
| 格式 | PNG（无透明背景）/ JPG |
| 大小 | ≤ 2MB（建议控制到1MB内以提升加载） |
| 圆角 | 不加圆角（系统自动裁切） |
| 边框 | 不加边框 |
| 水印 | 不含任何水印 |
| 禁止内容 | 不含微信/腾讯标识、不含"小游戏"字样 |
| 背景 | 必须有背景色（不能透明） |

### 2.2 图标设计建议
- 主体突出，占画面 60-80%
- 色彩鲜明，在小尺寸下仍可辨识
- 避免过多细节（缩小后看不清）
- 与游戏内容相关（消除→宝石、跑酷→角色）
- 避免文字（小图标上文字不可读）
- 参考同品类热门游戏的图标风格

### 2.3 其他图片规范
| 用途 | 尺寸 | 格式 | 备注 |
|------|------|------|------|
| 小游戏图标 | 方形PNG（建议512×512以上） | PNG/JPG | 必须 |
| 分享图片 | 5:4比例，≤128KB | PNG/JPG | 分享卡片用 |
| 游戏截图 | 750×1334px | PNG/JPG | 提审用，3-5张 |
| 加载背景 | 720×1280px | JPG | 可选 |

## 4. 素材授权注意事项

### 4.1 常见授权类型
| 授权 | 含义 | 能否商用 | 是否需署名 |
|------|------|---------|-----------|
| CC0 | 公共领域 | 可以 | 不需要 |
| CC-BY | 署名许可 | 可以 | 需要 |
| CC-BY-SA | 署名+相同方式共享 | 可以 | 需要+衍生同授权 |
| CC-BY-NC | 署名+非商业 | 不可以 | 需要 |
| GPL | 开源许可 | 可以（需开源） | 需要 |
| 免费商用 | 平台自定义 | 可以 | 看具体条款 |

### 4.2 安全使用原则
- 优先选择 CC0 素材（无任何限制）
- CC-BY 素材：在游戏"关于"页面注明出处
- 不要使用 NC（非商业）素材做广告变现的游戏
- 付费素材：保留购买凭证/授权证书
- AI生成素材：注意平台使用条款（部分不允许商用）
- 不要直接使用其他游戏的素材（即使"看起来差不多"）

### 4.3 侵权风险
- 字体侵权：最常见，赔偿 3000-50000元
- 图片侵权：视觉中国等维权，单张 500-5000元
- 音乐侵权：BGM版权方追诉，赔偿不等
- 防范：所有素材来源可追溯、保留授权证明

## 5. 音频设计基础

### 5.1 BGM（背景音乐）规范
| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 格式 | MP3 | 兼容性最好 |
| 码率 | 64-128kbps | 64k够用，128k品质好 |
| 采样率 | 44100Hz | 标准 |
| 声道 | 单声道 | 体积减半，游戏够用 |
| 时长 | 60-180秒循环 | 无缝循环 |
| 体积 | ≤ 500KB/首 | 远程加载可放宽 |

### 5.2 音效规范
| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 格式 | MP3（>0.5s）/ WAV（<0.5s） | 短音效WAV延迟低 |
| 码率 | 64kbps | 短音效不需要高码率 |
| 采样率 | 22050Hz | 音效够用 |
| 时长 | 0.1-3秒 | 简洁有力 |
| 数量 | 10-30个 | 覆盖所有交互 |

### 5.3 必备音效清单
```
基础音效（几乎所有游戏都需要）：
├── 按钮点击（click）
├── 按钮悬停/不可用（hover/disabled）
├── 成功/通过（success）
├── 失败/错误（fail/error）
├── 金币/奖励（coin/reward）
├── 消除/匹配（match/eliminate）
├── 倒计时（countdown）
├── 游戏开始（game_start）
├── 游戏结束（game_over）
└── 升级/解锁（levelup/unlock）

品类特有：
├── 消除类：交换、消除、连击、特殊道具
├── 跑酷类：跳跃、滑行、碰撞、加速
├── 放置类：建造、收获、升级
└── 卡牌类：抽取、出牌、攻击、受击
```

### 5.4 音量比例设计
```
推荐音量比例：
- BGM：40-60%（背景，不抢注意力）
- 音效：70-90%（清晰可辨）
- 语音（如有）：100%（最优先）

设计原则：
- BGM不能盖过音效
- 同类音效音量一致
- 连续触发时不刺耳（限制同时播放数）
- 重要反馈音效应突出（如通关、获得奖励）
```

### 5.5 静音按钮（必须）
- 游戏中必须提供静音/音量控制按钮
- 位置：通常在右上角或设置面板
- 分别控制：BGM开关 + 音效开关
- 默认状态：开启（但首次进入不自动播放BGM，等用户交互）
- 记住用户设置（本地存储）

```javascript
// 音频管理器示例
class AudioManager {
  constructor() {
    this.bgmEnabled = wx.getStorageSync('bgm_enabled') !== false;
    this.sfxEnabled = wx.getStorageSync('sfx_enabled') !== false;
    this.bgm = wx.createInnerAudioContext();
    this.bgm.loop = true;
    this.bgm.volume = 0.5;
  }

  playBGM(url) {
    if (!this.bgmEnabled) return;
    this.bgm.src = url;
    this.bgm.play();
  }

  playSFX(url) {
    if (!this.sfxEnabled) return;
    const sfx = wx.createInnerAudioContext();
    sfx.src = url;
    sfx.volume = 0.8;
    sfx.play();
    sfx.onEnded(() => sfx.destroy());
  }

  toggleBGM() {
    this.bgmEnabled = !this.bgmEnabled;
    wx.setStorageSync('bgm_enabled', this.bgmEnabled);
    if (this.bgmEnabled) this.bgm.play();
    else this.bgm.pause();
  }

  toggleSFX() {
    this.sfxEnabled = !this.sfxEnabled;
    wx.setStorageSync('sfx_enabled', this.sfxEnabled);
  }
}
```

## 6. 美术外包指导

### 6.1 外包渠道
| 渠道 | 适合 | 价格范围 | 特点 |
|------|------|---------|------|
| 站酷/花瓣 | 找设计师 | 按项目报价 | 品质高，价格高 |
| 淘宝/闲鱼 | 简单素材 | 50-500元/张 | 品质不稳定 |
| 米画师 | 插画/立绘 | 200-5000元/张 | 二次元风格多 |
| QQ群/贴吧 | 各类 | 差异大 | 需仔细筛选 |
| Fiverr/Upwork | 海外设计师 | $50-$500 | 风格多样 |
| 美术外包公司 | 批量需求 | 按项目 | 流程规范，价格高 |

### 6.2 外包流程
```
1. 明确需求
   ├── 风格参考图（3-5张）
   ├── 尺寸/格式要求
   ├── 数量清单
   ├── 交付时间
   └── 预算范围

2. 选择设计师
   ├── 看作品集（风格是否匹配）
   ├── 试稿（付费试1-2张）
   ├── 沟通响应速度
   └── 确认修改次数

3. 签订合同/协议
   ├── 交付标准
   ├── 知识产权归属（必须约定！）
   ├── 付款节点
   ├── 修改次数
   └── 违约责任

4. 过程管理
   ├── 草图确认 → 线稿确认 → 上色 → 完成
   ├── 每阶段确认后再进入下一步
   └── 保留源文件（PSD/AI）

5. 验收
   ├── 尺寸/格式正确
   ├── 风格统一
   ├── 细节完整
   └── 源文件交付
```

### 6.3 价格参考（2026年）
| 内容 | 价格范围 | 说明 |
|------|---------|------|
| 游戏图标 | 100-500元 | 简单图标低端即可 |
| UI界面（一套） | 500-3000元 | 含按钮/面板/弹窗 |
| 角色立绘（Q版） | 200-800元/个 | 含动作 |
| 角色立绘（半写实） | 800-5000元/个 | 精细度决定价格 |
| 场景背景 | 300-2000元/张 | 复杂度决定 |
| 消除元素（一套） | 200-1000元 | 20-50个元素 |
| 像素素材（一套） | 100-500元 | 像素风相对便宜 |
| 完整美术包（休闲游戏） | 2000-10000元 | 全套UI+元素+背景 |

### 6.4 验收标准
- [ ] 尺寸和分辨率符合要求
- [ ] 格式正确（PNG透明背景/JPG背景）
- [ ] 风格与参考图一致
- [ ] 无明显瑕疵（锯齿、色差、对齐问题）
- [ ] 命名规范（便于程序使用）
- [ ] 提供源文件（PSD/AI/Sketch）
- [ ] 切图完整（需要单独元素的已切好）
- [ ] 知识产权转让协议已签署

## 7. AI辅助美术工具

### 7.1 可用工具
| 工具 | 适合场景 | 费用 | 输出质量 |
|------|---------|------|---------|
| Midjourney | 概念图/背景/风格探索 | $10-60/月 | 高 |
| Stable Diffusion | 批量生成/风格控制 | 免费（本地） | 中-高 |
| DALL-E | 快速概念/图标参考 | 按量付费 | 中-高 |
| 通义万相 | 国内可用/中文理解好 | 免费额度 | 中 |
| Remove.bg | 抠图/去背景 | 免费额度 | 高 |
| Upscale.media | 图片放大/超分 | 免费额度 | 高 |

### 7.2 AI美术工作流
```
推荐流程：
1. AI生成概念图/参考图（确定风格方向）
2. AI生成初稿（批量出图，择优选择）
3. 人工修改调整（统一风格、修复细节）
4. 后期处理（调色、裁切、适配尺寸）
5. 合图/导出（TexturePacker）

适用场景：
- 背景图/场景概念
- 图标/元素初稿
- 配色方案探索
- 大量相似元素（如消除方块）

不适用场景：
- 需要精确像素对齐的UI
- 需要多帧动画的角色
- 需要严格风格统一的成套素材（AI一致性差）
```

### 7.3 合规使用注意
- **版权风险**：AI生成图片的版权归属尚有争议
- **平台条款**：部分AI工具禁止商用（使用前确认）
- **风格侵权**：不要指定"模仿知名游戏风格"（如"模仿头部开放世界游戏"）
- **建议**：
  - AI作为辅助参考，最终素材人工调整
  - 保留生成记录和修改过程
  - 不直接商用AI原图（做二次创作）
  - 关注国内AI生成内容版权政策变化
  - 提审时如被质疑，能提供创作过程证明

### 7.4 实用提示词模板
```
游戏素材生成提示词结构：
[主体描述] + [风格] + [视角] + [背景] + [技术要求]

示例：

transparent background, game asset, clean edges,

"pixel art treasure chest, 32x32, 4-frame opening
animation, retro RPG style, transparent background"
```
