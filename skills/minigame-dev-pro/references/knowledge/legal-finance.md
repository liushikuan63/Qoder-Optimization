# 法律与财务基础

> 面向小游戏开发者的法律财务实用指南。非专业法律意见，重大事项请咨询专业人士。

---

## 1. 主体选择对比

### 1.1 三种主体对比

| 维度 | 个人（自然人） | 个体工商户 | 有限公司 |
|------|--------------|-----------|---------|
| **适合谁** | 试水阶段、月收入<5000 | 稳定收入、年入10-50万 | 团队运营、年入>50万、需融资 |
| **注册成本** | 0元 | 0-500元 | 500-2000元（代办） |
| **注册难度** | 无需注册 | 简单（1-3天） | 中等（3-7天） |
| **微信小游戏** | 可注册（部分功能受限） | 可注册（企业类） | 可注册（全功能） |
| **虚拟支付** | 不支持 | 支持 | 支持 |
| **广告收入** | 支持 | 支持 | 支持 |
| **法律责任** | 无限责任 | 无限责任 | 有限责任（以出资额为限） |
| **税务复杂度** | 简单 | 中等 | 复杂 |
| **开票能力** | 不能 | 可以（代开/自开） | 可以 |
| **品牌形象** | 弱 | 中 | 强 |
| **注销难度** | - | 简单 | 复杂（需清算） |

### 1.2 个人主体
**优势**：
- 零成本启动
- 无需记账报税（平台代扣）
- 适合验证想法

**劣势**：
- 不能开通虚拟支付（微信小游戏虚拟支付仅 Android 支持，API `wx.requestMidasPayment`；iOS 未开放，个人主体不可开通）
- 部分高级功能不可用
- 广告收入按劳务报酬扣税（税率较高）
- 无法开企业发票
- 品牌保护弱

### 1.3 个体工商户
**优势**：
- 注册简单、成本低
- 可以企业身份注册小游戏
- 税负相对较低（经营所得）
- 可以开发票
- 无需严格记账（小规模可定额征收）

**劣势**：
- 无限责任（个人财产担保）
- 不能融资/股权分配
- 品牌信任度有限
- 规模做大后需要转型

### 1.4 有限公司
**优势**：
- 有限责任（风险隔离）
- 全功能开放
- 可融资、股权分配
- 品牌正规
- 税务筹划空间大

**劣势**：
- 注册和维护成本高
- 需要记账报税（每月/每季）
- 双重征税（企业所得税+分红个税）
- 注销麻烦
- 需要银行账户、税务登记等

## 2. 税务基础

### 2.1 个人（劳务报酬）
```
微信广告收入 → 平台代扣个人所得税（劳务报酬）

税率表（预扣预缴）：
- 每次收入 ≤ 800元：免税
- 800 < 收入 ≤ 4000元：(收入-800) × 20%
- 收入 > 4000元：收入 × (1-20%) × 对应税率

年度汇算清缴：
- 并入综合所得（3%-45%超额累进）
- 年收入 ≤ 6万基本不用补税
- 年收入 6-12万：实际税率约 3-10%
```

### 2.2 个体工商户
```
需缴税种：
1. 增值税：
   - 小规模纳税人：季度 ≤ 30万免征（2026年政策，以最新为准）
   - 超出部分：1%（优惠期）/ 3%（标准）

2. 个人所得税（经营所得）：
   - 5%-35% 五级超额累进
   - 年应纳税所得额 ≤ 3万：5%
   - 3万-9万：10%
   - 9万-30万：20%
   - 30万-50万：30%
   - > 50万：35%
   - 部分地区可核定征收（税率更低）

3. 附加税：增值税的6-12%（金额小可忽略）

示例：年利润20万
- 增值税：季度<30万免征
- 经营所得税：3万×5% + 6万×10% + 11万×20% = 1500+6000+22000 = 29500元
- 实际税负率：约15%
```

### 2.3 有限公司
```
需缴税种：
1. 增值税：同上（小规模/一般纳税人）

2. 企业所得税：
   - 标准税率：25%
   - 小微企业优惠：
     - 年利润 ≤ 300万：实际税率5%（2026年，以最新政策为准）
   - 高新技术企业：15%

3. 分红个人所得税：
   - 税后利润分红：20%

综合税负示例：年利润50万
- 企业所得税：50万 × 5% = 2.5万
- 税后利润：47.5万
- 分红个税：47.5万 × 20% = 9.5万
- 总税负：12万（税负率24%）
- 对比个体户：同样50万利润，经营所得约8万（税负率16%）

注意：公司利润不分红则不缴分红税（可用于再投资）
```

### 2.4 税务筹划建议
- 年收入 < 10万：个人即可，平台代扣省心
- 年收入 10-50万：注册个体户，税负最优
- 年收入 > 50万：考虑公司（有限责任+再投资）
- 保留所有成本票据（设备、外包、软件订阅）
- 按时申报（即使零收入也要零申报）

## 3. 什么时候该注册主体

### 3.1 决策树
```
当前状态评估：
│
├── 还在开发/未上线 → 个人即可
│
├── 已上线，月收入 < 5000 → 个人即可
│
├── 月收入 5000-1万，稳定 → 考虑个体户
│   └── 原因：税负优化、可开发票
│
├── 月收入 > 1万（年入>10万） → 建议个体户
│   └── 原因：税负明显优化、正规化
│
├── 月收入 > 4万（年入>50万） → 考虑公司
│   └── 原因：有限责任、税务筹划空间
│
├── 需要虚拟支付功能 → 必须企业主体（个体户/公司）
│
├── 有合伙人/团队 → 必须公司（股权分配）
│
└── 需要融资 → 必须公司
```

### 3.2 注册个体户流程
1. 确定经营场所（可用住宅，部分地区需证明）
2. 核名（当地市场监管局网站/APP）
3. 提交材料（身份证、经营场所证明、申请表）
4. 领取营业执照（1-3个工作日）
5. 税务登记（自动关联或手动）
6. 开银行账户（可选）
7. 在微信后台更新主体信息

### 3.3 注册公司流程
1. 核名（准备3-5个备选名称）
2. 确定注册资本（认缴制，建议10-100万）
3. 确定股东/法人/监事
4. 提交注册材料（线上/线下）
5. 领取营业执照
6. 刻章（公章/财务章/法人章）
7. 银行开户
8. 税务登记+税种核定
9. 每月记账报税（找代账公司200-500元/月）

## 4. 知识产权

### 4.1 软件著作权（软著）
| 项目 | 说明 |
|------|------|
| 保护对象 | 代码（源代码+文档） |
| 费用 | 官费0元（自己申请）/ 代办800-1500元（普通）/2000-5000元（加急） |
| 时间 | 自己申请约2-3个月 / 加急1-30天（加急费另算） |
| 有效期 | 作者终身+死后50年 / 法人50年 |
| 用途 | 小游戏备案必需、维权依据、高新认证 |
| 申请地址 | 中国版权保护中心（www.ccopyright.com.cn） |

**申请要点**：
- 源代码：前后各30页（约60页，每页50行）
- 说明文档：用户手册/设计文档（15-30页）
- 名称格式：软件全称 = 游戏名称（不加 V1.0/软件/系统 等任何后缀，与微信后台及游戏内名称一字不差；软著证书名称与平台名称一致性要求，需以中国版权保护中心及微信平台最新要求为准）

### 4.2 商标
| 项目 | 说明 |
|------|------|
| 保护对象 | 游戏名称、LOGO |
| 费用 | 官费300元/类（网上申请）/ 代办800-1500元 |
| 时间 | 9-12个月（含公告期） |
| 有效期 | 10年（可续展） |
| 类别 | 第9类（软件）、第41类（娱乐）、第42类（技术服务） |
| 申请地址 | 国家知识产权局商标局（sbj.cnipa.gov.cn） |

**建议**：
- 游戏上线前就申请商标（避免被抢注）
- 至少注册第9类和第41类
- 名称确定后再申请（避免浪费）
- 被抢注可提异议（公告期内）或无效宣告

### 4.3 美术版权
- 原创美术作品自动享有版权（创作完成即有）
- 建议做版权登记（中国版权保护中心）
- 费用：官费100-300元/件
- 保留创作过程证据（源文件、时间戳）
- 外包美术：合同中明确版权归属

### 4.4 音乐版权
- 使用免费素材：保留授权证明
- 委托创作：合同约定版权归属
- 不要使用未授权的商业音乐
- 音效包购买：确认是"买断"还是"授权"
- AI生成音乐：版权政策尚不明确，谨慎使用

## 5. 外包合同要点

### 5.1 必须约定的条款
```
1. 交付标准
   ├── 具体交付物清单（数量、格式、尺寸）
   ├── 质量标准（参考图/风格指南）
   ├── 交付时间（里程碑节点）
   └── 交付方式（网盘/邮件/项目管理工具）

2. 知识产权归属（最重要！）
   ├── 明确约定：成果版权归委托方（你）所有
   ├── 包括：修改权、改编权、信息网络传播权
   ├── 源文件必须交付
   └── 未经同意不得用于其他项目/展示

3. 付款节点
   ├── 签约：30%（启动）
   ├── 草图/初稿确认：30%
   ├── 终稿交付：30%
   └── 验收通过：10%（尾款）

4. 修改约定
   ├── 免费修改次数（通常3次）
   ├── 超出修改的计费标准
   ├── 修改范围界定（微调vs重做）
   └── 修改响应时间

5. 违约责任
   ├── 延期交付：每日扣X%
   ├── 质量不达标：免费修改/退款
   ├── 版权纠纷：由创作者承担
   └── 单方面终止：已完成部分按比例付款
```

### 5.2 合同模板关键条款
```
第X条 知识产权
甲方（委托方）支付全部费用后，本合同项下所有交付物的
著作权（包括但不限于复制权、发行权、信息网络传播权、
改编权）归甲方所有。乙方不得将交付物用于任何其他项目，
包括但不限于个人作品集展示（除非获得甲方书面同意）。

第X条 保密条款
乙方不得向第三方透露本合同内容、甲方项目信息及
未公开的游戏设计内容。保密期限：合同终止后2年。
```

## 6. 广告收入结算到账

### 6.1 微信广告收入结算
| 项目 | 说明 |
|------|------|
| 结算周期 | 月结（每月1日-月末为一个结算周期） |
| 数据确认 | 次月15日左右可查上月收入 |
| 结算门槛 | 累计 ≥ 100元 |
| 到账时间 | 申请后7-15个工作日 |
| 到账方式 | 个人→银行卡 / 企业→对公账户 |

### 6.2 税务处理
- **个人主体**：微信代扣个人所得税（劳务报酬），到手即税后
- **企业主体**：
  - 微信不代扣税
  - 需自行申报增值税+企业所得税
  - 可开具发票给微信（腾讯）
  - 建议找代账公司处理

### 6.3 收入记录建议
```
每月记录：
- 广告展示量/点击量
- eCPM
- 总收入（税前）
- 已结算金额
- 应缴税费
- 实际到手

工具：简单Excel表格即可
目的：年度汇算、税务申报、经营分析
```

## 7. 常见法律风险

### 7.1 高频风险清单
| 风险 | 后果 | 预防措施 |
|------|------|---------|
| 字体侵权 | 赔偿3000-50000元 | 只用免费商用字体 |
| 图片侵权 | 赔偿500-5000元/张 | 素材来源可追溯 |
| 音乐侵权 | 赔偿+下架 | 用免费/已授权音乐 |
| 游戏抄袭 | 下架+赔偿 | 玩法可借鉴，美术代码必须原创 |
| 无软著/备案 | 不能上架/被下架 | 提前办理 |
| 商标被抢注 | 被迫改名/高价赎回 | 上线前注册商标 |
| 外包版权纠纷 | 素材不能使用 | 合同明确版权归属 |
| 用户数据违规 | 罚款+下架 | 遵守个保法、隐私政策 |
| 虚假宣传 | 罚款 | 广告内容真实 |
| 未成年人保护 | 罚款+下架 | 接入防沉迷（如有需要） |

### 7.2 隐私合规要点
- 必须有隐私政策（首次启动弹窗告知）
- 收集用户信息需明示+同意
- 不能过度收集（只收集必要信息）
- 用户可注销账号/删除数据
- 儿童信息保护（14岁以下需监护人同意）
- 参考：相关隐私保护法规及儿童个人信息保护规定

### 7.3 游戏内容合规
- 不得含有违反平台内容安全规范的元素
- 不得违规分享奖励（"分享后解锁"需谨慎）
- 随机机制需公示概率
- 不得有歧视性内容
- 历史题材需尊重史实

### 7.4 维权途径
- 发现被抄袭：微信投诉 → 版权局投诉 → 法律诉讼
- 被恶意投诉：准备原创证据 → 申诉 → 必要时法律途径
- 合同纠纷：协商 → 调解 → 仲裁/诉讼
- 建议：保留所有创作过程记录（Git提交、设计稿版本、沟通记录）
