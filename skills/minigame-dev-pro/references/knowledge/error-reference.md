﻿# 错误码与退出码参考手册

> 本文件汇总 Skill 所有脚本的退出码、常见错误及处理建议。
> 最后更新：2026-08-05

---

## 通用退出码

| 退出码 | 含义 | 通用场景 |
|--------|------|---------|
| 0 | 成功 | 脚本正常执行完成，无错误 |
| 1 | 执行失败 | 参数错误、路径不存在、运行时异常 |
| 非0 | 异常退出 | 具体含义见各脚本说明 |

---

## 各脚本退出码详解

### compliance-scan.mjs — 合规红线扫描

| 退出码 | 含义 | 说明 |
|--------|------|------|
| 0 | 扫描完成，无违规 | 所有检查项通过（含 warning 不阻断） |
| 1 | 参数错误或路径不存在 | 缺少 `--project` 或路径无效 |
| 1 | 存在阻断性违规 | 检测到 severity=block 的违规项 |

**常见错误：**
- `缺少必填参数 --project` → 项目路径未指定
- `项目路径不存在` → 路径无效

---

### publish.mjs — 上传发布

| 退出码 | 含义 | 说明 |
|--------|------|------|
| 0 | 上传成功 | 代码已上传到微信后台 |
| 1 | 参数校验失败 | 缺少 `--project`、`--version` 或 `--confirm yes` |
| 1 | 版本号格式错误 | 不符合 semver 规范（如 `1.0`、`1.0.0<bad>`） |
| 1 | 项目路径不存在 | 指定路径无效 |
| 1 | 上传失败 | CLI 返回错误 |

**常见错误：**
- `缺少必填参数 --project` → 项目路径未指定
- `缺少必填参数 --version` → 版本号未指定
- `--confirm yes 未指定` → 上传不可逆操作需显式确认
- `版本号格式不正确` → 必须符合 `主.次.修` 格式

---

### perf-profiler.mjs — 性能打点

| 退出码 | 含义 | 说明 |
|--------|------|------|
| 0 | inject/revert 成功 | 注入或恢复完成 |
| 1 | 参数错误 | 缺少 `--project`、`--mode` 无效 |
| 1 | .bak 已存在 | 再次 inject 被拒绝（防止覆盖备份） |
| 1 | 未找到 game.js | 项目路径下无入口文件 |

**常见错误：**
- `mode 参数必须为 inject/read/revert` → `--mode` 值无效
- `.bak 已存在，拒绝覆盖` → 需先 revert 再 inject

### sop-timeliness-check.mjs — SOP 时效巡检

| 退出码 | 含义 | 说明 |
|--------|------|------|
| 0 | 全部健康 | 所有 SOP 均为 ok 或 due-soon 状态 |
| 1 | 存在需处理项 | 存在 overdue / missing-meta / malformed-date |

**状态说明：**
| 状态 | 含义 | 处理方式 |
|------|------|---------|
| ok | 未到期 | 无动作 |
| due-soon | 14天内到期 | 提示安排核实 |
| overdue | 已过期 | 标记待核实，启动核实流程 |
| missing-meta | 缺元数据 | P0 缺陷，需补全 |
| malformed-date | 日期格式非法 | P0 缺陷，需修正 |

---

### asset-check.mjs — 素材版权检查

| 退出码 | 含义 | 说明 |
|--------|------|------|
| 0 | 扫描完成 | 输出素材检查结果和风险等级 |
| 1 | 参数错误或路径不存在 | 缺少 `--project` 或路径无效 |

**风险等级：**
| 等级 | 含义 | 建议 |
|------|------|------|
| safe | 无风险 | 通过 |
| low_risk | 低风险（超大文件） | 建议确认 |
| medium_risk | 中风险（AI生成标记） | 建议确认商用授权 |
| high_risk | 高风险（文件名含版权关键词） | 必须确认版权或替换 |

### package-analyzer.mjs — 包体分析

| 退出码 | 含义 | 说明 |
|--------|------|------|
| 0 | 分析完成 | 输出包体大小和优化建议 |
| 1 | 参数错误或路径不存在 | 缺少 `--project` 或路径无效 |

**包体基准（微信口径；平台硬上限：主包≤4MB / 总包≤30MB / 独立分包≤4MB，见 `tech-specs.md`）：**
| 指标 | 健康 | 警告 | 超标 |
|------|------|------|------|
| 主包 | ≤ 3MB | 3-4MB | > 4MB（主包硬上限） |
| 总包 | ≤ 15MB | 15-25MB | > 30MB（平台硬上限） |
| 独立分包 | ≤ 3MB | 3-4MB | > 4MB（独立分包硬上限） |

> 注：上表「健康/警告」为微信小游戏**性能质量建议值**（包体越小启动越快），「超标」列对齐平台硬上限。抖音口径不同（非分包≤16MB、分包整体≤20MB/+VP 30MB），见 `references/data/spec-registry.json` SP-011，禁止套用微信数值。

## 全局错误处理建议

### 微信开发者工具相关

| 错误现象 | 可能原因 | 修复建议 |
|---------|---------|---------|
| CLI 命令未找到 | 未安装微信开发者工具 | 下载并安装微信开发者工具 |
| CLI 超时 | 项目过大或网络问题 | 增加 `--timeout` 参数 |
| 登录态失效 | 未登录微信开发者工具 | 打开开发者工具并扫码登录 |
| automator 连接失败 | 调试端口未开启 | 在开发者工具中开启「工具→调试→调试端口」 |

### Node.js 相关

| 错误现象 | 可能原因 | 修复建议 |
|---------|---------|---------|
| `SyntaxError: Cannot use import statement` | Node.js 版本过低 | 升级到 Node.js 18+ |
| `ERR_MODULE_NOT_FOUND` | 本地模块路径错误 | 检查相对路径是否正确 |
| EACCES 权限错误 | 文件/目录无权限 | 以管理员身份运行或修改权限 |

### 项目路径相关

| 错误现象 | 处理方式 |
|---------|---------|
| 路径不存在 | 确认项目路径正确，使用绝对路径或正确相对路径 |
| 路径不是小游戏项目 | 确认路径包含 `game.js` 和 `game.json` |
| 路径包含中文/空格 | 建议使用不含中文和空格的路径（某些CLI版本有兼容问题） |
