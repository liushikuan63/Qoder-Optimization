# 难度平衡方法论（Difficulty Balancing）

> **核心理念**：难度不是「越难越好」，而是让玩家始终处于**心流通道**——
> 挑战略高于当前技能，既不太简单（无聊）也不太困难（焦虑）。
> 好的难度设计让玩家失败后觉得「差一点就赢了，再来一次」。

---

## 1. 心流通道（Flow Channel）

### 1.1 心流模型
```
焦虑区 ▲
        │      ╱ 心流通道
        │    ╱   （挑战 ≈ 技能 + 一点点）
        │  ╱
        │╱____________
        │  无聊区
        └──────────────► 技能提升
```

- **挑战 > 技能太多** → 焦虑 → 流失
- **挑战 < 技能太多** → 无聊 → 流失
- **挑战 ≈ 技能 + 适度压力** → 心流 → 沉浸 + 留存

### 1.2 设计原则
- 难度随玩家成长**动态上升**
- 每引入一个新机制，先给「教学关」让玩家掌握，再考核
- 难度曲线是「波浪形」而非「直线上升」：紧张 → 释放 → 紧张

## 2. 难度曲线设计（标准节奏）

### 2.1 前 10 关黄金节奏

| 关卡 | 设计目标 | 难度 |
|------|---------|------|
| 第 1-5 关 | **极简**，纯教学，让玩家建立信心和爽感 | ★☆☆☆☆ |
| 第 6 关 | 引入**第一个新机制**（如新道具/新障碍） | ★★☆☆☆ |
| 第 7-9 关 | 练习新机制，难度缓升 | ★★☆☆☆ |
| 第 10 关 | **小 Boss / 小高峰**，综合运用所学 | ★★★☆☆ |
| 第 11-15 关 | Boss 后释放，难度回落，给奖励 | ★★☆☆☆ |
| 第 16-20 关 | 引入第二个新机制，难度再爬升 | ★★★☆☆ |
| 第 20 关 | 第二个 Boss / 章节高峰 | ★★★★☆ |

### 2.2 波浪形难度曲线
```
难度
 ▲
 │        ╱╲      ╱╲      ╱╲  ← Boss/高峰
 │      ╱    ╲  ╱    ╲  ╱
 │    ╱        ╲        ╲    ← 释放/奖励关
 │  ╱
 └──────────────────────────► 关卡
```
- 每 5-10 关一个难度峰值（Boss/挑战关）
- 峰值后必有**释放关**（简单 + 高奖励），让玩家喘息 + 获得成就感
- 整体趋势上升，但局部有起伏

### 2.3 难度增量控制
- 相邻关卡难度增量 5%-10%
- 新机制引入当关，难度不增反降（让玩家专注学习）
- 每 20-30 关一个「难度台阶」，需要养成/技巧提升才能跨越

## 3. 失败设计（让玩家觉得「差一点就赢了」）

### 3.1 失败设计的黄金法则
> 玩家失败后的第一反应应该是「**哎呀差一点！**」而不是「**这根本不可能**」。

### 3.2 实现手法

| 手法 | 说明 | 示例 |
|------|------|------|
| **可视化进度** | 让玩家看到自己离成功多近 | 进度条到 95%、Boss 剩 5% 血 |
| **步数/时间差一点** | 失败时只差 1 步/1 秒 | 消除「还差 1 步就通关」 |
| **可归因失败** | 失败原因清晰，玩家知道怎么改 | 「刚才那个障碍该跳早一点」 |
| **快速重试** | 失败后一键重开，无惩罚 | 0 等待重玩 |
| **鼓励性文案** | 失败界面正向引导 | 「太可惜了！再来一次」 |
| **失败奖励** | 失败也给一点安慰奖 | 给少量金币/经验 |

### 3.3 失败的变现转化
- 失败瞬间是**激励视频转化最高点**：
  - 「+5 步继续」看广告
  - 「复活一次」看广告
  - 「本次奖励翻倍」看广告
- ⚠️ 但失败不能是「设计出来逼玩家看广告」，否则口碑崩塌

### 3.4 避免的失败体验
- ❌ 莫名其妙失败（不知道为啥死）
- ❌ 失败后漫长等待/惩罚
- ❌ 失败界面全是广告弹窗
- ❌ 难度断崖（突然从简单变不可能）

## 4. 动态难度调整（DDA）

### 4.1 什么是 DDA
Dynamic Difficulty Adjustment：根据玩家表现**实时调整**难度，让不同水平玩家都留在心流通道。

### 4.2 实现方式

| 方式 | 说明 | 适用品类 |
|------|------|---------|
| **隐性调整** | 连败 N 次后暗中降低难度（增加道具掉落/降低敌人血量） | 消除、解谜 |
| **道具救济** | 连败后免费送道具/提示 | 全品类 |
| **关卡分支** | 失败后提供「简单模式」选项 | 解谜、动作 |
| **匹配调整** | PVP 中按水平匹配对手 | 竞技类 |
| **随机倾斜** | 连败后提高有利随机事件概率 | 卡牌、Roguelike |

### 4.3 DDA 注意事项
- **必须隐性**：玩家不能察觉难度被调整，否则觉得「被施舍」
- **保留上限**：高手玩家不应被「拉低」，DDA 主要救济菜鸟
- **不破坏公平**：PVP 中 DDA 要谨慎，避免「橡皮筋」体验

### 4.4 简易 DDA 伪代码
```
if 玩家在当前关卡连败 >= 3:
    下一局难度系数 ×= 0.85   # 降低 15%
    额外赠送 1 个道具
if 玩家连续通关 >= 5 且用时短:
    下一局难度系数 ×= 1.10   # 提升 10%（挑战高手）
```

## 5. 各品类难度设计要点

### 5.1 消除类
- 步数限制是核心难度杠杆
- 棋盘随机性：保证大多数局面有解，避免「死局」
- 难度通过「目标类型 + 步数 + 棋盘布局」三维控制
- 每 10 关一个「卡点关」，但提供道具救济

### 5.2 放置/挂机类
- 难度 = 数值门槛（战力/产出不足）
- 通过「等待 + 升级」自然跨越，而非操作技巧
- 卡点用「转生」机制释放

### 5.3 合成类
- 难度 = 棋盘空间压力 + 订单复杂度
- 避免「无解」局面（保证有合成路径）
- 空间管理是核心策略深度

### 5.4 模拟经营
- 难度低，以「目标引导」代替「失败惩罚」
- 等待时间是主要「难度」（用加速/广告缓解）
- 不应让玩家「经营失败破产」

### 5.5 卡牌/策略
- 难度 = 阵容克制 + 数值养成 + 操作策略
- Roguelike 随机性提供重玩难度变化
- PVE 关卡 + 竞技场分层

### 5.6 动作/跑酷
- 难度 = 速度 + 障碍密度 + 反应要求
- 速度渐进：单局内越来越快
- 操作响应必须 < 100ms，否则难度失真

### 5.7 解谜类
- 难度 = 思维跳跃度
- 提示系统分级：免费提示 → 看广告提示 → 直接跳过
- 避免「脑洞过大」导致玩家完全无从下手

### 5.8 塔防类
- 难度 = 波次强度 + 塔种搭配要求
- 提供「先试后买」的塔种试用
- Boss 波次前给准备时间

## 6. 难度平衡测试方法

### 6.1 关卡通过率监控
- 每关记录通过率
- **健康区间**：普通关 70%-90%，Boss 关 40%-60%
- 通过率 < 30% → 难度过高，需调整
- 通过率 > 95% → 难度过低，无挑战

### 6.2 流失点定位
- 找出流失率最高的关卡
- 分析是「难度问题」还是「引导问题」
- 针对性调整

### 6.3 A/B 测试
- 同一关卡不同难度分组测试
- 对比通过率、重试率、流失率、广告转化

## 7. 难度设计检查清单

- [ ] 前 5 关是否极简，建立信心？
- [ ] 新机制是否有教学关？
- [ ] 难度曲线是否波浪形（有释放关）？
- [ ] 失败是否「差一点就赢」？
- [ ] 失败后能否快速重试？
- [ ] 是否有 DDA 救济连败玩家？
- [ ] 各关通过率是否在健康区间？
- [ ] 高手玩家是否仍有挑战？
