# 经济系统设计指南（Economy Design）

> **核心目标**：经济系统是游戏的「血液循环」。好的经济系统让玩家**永远缺一点、永远想再玩一局**，
> 同时让免费玩家玩得下去、付费玩家有优势但不碾压、广告变现不破坏平衡。

---

## 1. 资源类型

### 1.1 软货币（Soft Currency）
- **定义**：金币、银币等，通过游玩大量产出
- **用途**：基础升级、建造、购买普通道具
- **特点**：产出充足，消耗也充足，保持流动
- **设计要点**：让玩家「赚得多花得也多」，体验富足感

### 1.2 硬货币（Hard Currency）
- **定义**：钻石、元宝等，产出稀缺
- **用途**：随机抽取、加速、购买稀有道具、兑换软货币
- **来源**：付费购买、成就奖励、活动、（少量）广告
- **设计要点**：硬货币是**付费锚点**，免费获取要克制

### 1.3 体力/能量（Energy）
- **定义**：限制单局游玩次数的资源
- **用途**：进入关卡/战斗
- **恢复**：时间恢复（如 5 分钟/点）、广告补充、付费购买
- **设计要点**：体力是**留存 + 变现**双重工具，但不可过苛（见反模式）

### 1.4 道具（Items）
- **消耗品**：增益、复活、跳过（看广告/付费获取）
- **永久品**：皮肤、角色、装饰（付费/活动获取）
- **设计要点**：道具要有明确的「使用场景」和「价值感」

### 1.5 资源关系图
```
付费 ──→ 硬货币 ──→ 随机抽取/加速/稀有道具
              │
              ↓ 兑换
广告 ──→ 软货币 / 体力 / 道具 ──→ 基础升级/通关
              ↑
            游玩产出
```

## 2. 产出与消耗平衡

### 2.1 水龙头-水槽模型
- **水龙头（产出源）**：关卡通关、签到、任务、广告、付费
- **水槽（消耗口）**：升级、随机抽取、建造、复活、加速
- **平衡原则**：长期看，产出略小于消耗，制造「稀缺感」

### 2.2 平衡表（示例，需按品类调整）

| 资源 | 日产出来源 | 日产出量 | 日消耗去向 | 日消耗量 | 净流向 |
|------|-----------|---------|-----------|---------|--------|
| 金币 | 通关/任务 | 5000 | 升级/建造 | 5500 | -500（微缺） |
| 钻石 | 成就/活动 | 50 | 随机抽取/加速 | 60 | -10（微缺） |
| 体力 | 时间恢复 | 120 | 通关 | 130 | -10（广告补） |

> 设计意图：让玩家**每天差一点点**，这个「一点点」就是广告/付费的转化空间。

### 2.3 平衡校验
- 模拟一个免费玩家：每天玩 30 分钟，能否在不看广告的情况下推进？（应能，但慢）
- 模拟一个看广告玩家：每天看 5 次广告，体验是否流畅？（应是）
- 模拟一个付费玩家：付费是否带来明显但不破坏的体验提升？（应是）

## 3. 通胀控制

### 3.1 通胀的危害
- 后期玩家金币堆积 → 升级毫无压力 → 失去挑战 → 流失
- 数值膨胀 → 新玩家望而却步

### 3.2 控制手段
1. **指数成本**：升级成本 = base × 1.15^level，消耗随等级指数增长
2. **新水槽**：定期开放新消耗口（新建筑、新角色、新养成线）
3. **赛季重置**：竞技场/排行赛季重置，部分资源清零
4. **绑定货币**：活动货币限时使用，过期作废
5. **税收/损耗**：交易、复活等收取一定比例损耗

### 3.3 数值健康监控
- 监控玩家各等级金币存量分布
- 若大量玩家金币溢出 → 增加消耗口或降低产出
- 若大量玩家卡在「没钱升级」→ 适当增加产出

## 4. 付费设计

### 4.1 免费玩家体验（底线）
- **必须能通关**：免费玩家可以体验到全部核心内容，只是慢
- **不能被碾压**：PVE 为主的游戏，免费玩家不被付费玩家碾压
- **有尊严**：免费玩家也有成长感和成就感

### 4.2 付费玩家优势（合理范围）
- **加速**：跳过等待时间（建造/恢复）
- **便利**：自动收集、额外背包格
- **外观**：皮肤、特效（不影响数值或影响很小）
- **稀缺**：限定角色/卡牌（收集价值 > 数值价值）

### 4.3 付费点设计
| 付费点 | 类型 | 说明 |
|--------|------|------|
| 首充礼包 | 高性价比 | 6 元给超值奖励，破冰付费 |
| 月卡 | 订阅 | 每日领钻石，培养付费习惯 |
| 随机抽取 | 概率 | 卡牌类核心付费点 |
| 皮肤 | 外观 | 跑酷/动作类核心付费点 |
| 去广告 | 体验 | 一次性付费移除插屏（保留激励视频） |
| 通行证 | 赛季 | 免费线 + 付费线双轨奖励 |

### 4.4 付费红线
- ❌ 不卖「数值碾压」（PVP 中付费直接吊打免费）
- ❌ 不做「pay to win」逼氪卡关
- ❌ 不做概率不公示的随机抽取（合规要求公示概率）
- ✅ 付费 = 加速 + 外观 + 便利，而非「不付费不能玩」

---

## 5. 广告变现嵌入（不破坏经济平衡）

### 5.1 激励视频（推荐，eCPM 最高）
**嵌入原则**：玩家**主动选择**看广告换取奖励，且奖励是「锦上添花」而非「必需品」。

| 嵌入点 | 奖励 | 平衡性 |
|--------|------|--------|
| 通关奖励翻倍 | 金币 ×2 | ✅ 不翻倍也能玩 |
| 离线收益翻倍 | 挂机收益 ×2 | ✅ 放置类高转化点 |
| 复活/续命 | 多一次机会 | ✅ 不复活可重开 |
| 补充体力 | +20 体力 | ✅ 也可等时间恢复 |
| 免费抽一次 | 单抽 | ✅ 不破坏卡池经济 |

### 5.2 插屏广告（谨慎）
- 仅在**自然停顿点**展示：通关结算后、返回主页时
- 频率控制：每 3-5 分钟最多 1 次
- ❌ 绝不在操作过程中、失败瞬间弹窗

### 5.3 Banner 广告（低 eCPM，慎用）
- 仅在非核心界面（设置、图鉴）展示
- 不遮挡操作区域

### 5.4 广告经济平衡校验
- 看广告获得的资源 < 付费获得的资源（保持付费价值）
- 看广告不能让玩家「无限刷资源」破坏经济（设每日上限）
- 广告奖励是「加速」而非「跳过」核心循环

## 6. 数值公式参考

### 6.1 升级成本（指数增长）
```
cost(level) = base_cost × growth_rate ^ level
```
- growth_rate 常用 1.12 - 1.20
- 例：base=100, rate=1.15 → Lv10 成本 ≈ 405，Lv50 成本 ≈ 108,366

### 6.2 产出增长（线性/指数）
```
产出(level) = base_output × level        # 线性
产出(level) = base_output × 1.10 ^ level # 指数（放置类）
```

### 6.3 战斗伤害
```
伤害 = 攻击力 × 技能倍率 × (1 - 防御减伤) × 暴击系数
防御减伤 = 防御 / (防御 + 常数K)   # K 控制减伤曲线，避免无敌
```

### 6.4 随机抽取概率（合规公示）
```
单抽 SSR 概率 = 1.5%（示例，需公示）
保底机制：N 抽必出 SSR（如 80 抽保底）
```

### 6.5 LTV 估算
```
ARPDAU = 日总收入 / DAU
LTV = ARPDAU × 平均生命周期(天)
```

## 7. 经济系统设计检查清单

- [ ] 资源类型清晰（软/硬/体力/道具各司其职）？
- [ ] 产出 < 消耗，制造合理稀缺？
- [ ] 有通胀控制手段（指数成本/新水槽/赛季）？
- [ ] 免费玩家能通关、有尊严？
- [ ] 付费 = 加速 + 外观，非数值碾压？
- [ ] 随机抽取概率已公示（合规）？
- [ ] 广告奖励是「加速」非「跳过」，且有日上限？
- [ ] 插屏只在自然停顿点、频率受控？
- [ ] 数值公式可持续（不会后期崩坏）？
