# 核心循环设计模式库（Core Loop Patterns）

> **核心理念**：核心循环是玩家在游戏中**重复执行的最小有趣单元**。好的循环让玩家「再来一局」停不下来。
> 每个模式按三层时间尺度设计：**微循环（30 秒）→ 中循环（3-5 分钟）→ 宏循环（30 分钟+）**。

---

## 通用框架

| 层级 | 时长 | 玩家心理 | 设计目标 |
|------|------|---------|---------|
| 微循环 | 30 秒 | 「这个动作好爽」 | 即时反馈、操作快感 |
| 中循环 | 3-5 分钟 | 「再来一局就赢」 | 单局完整体验、小目标达成 |
| 宏循环 | 30 分钟+ | 「我变强了/解锁新东西」 | 成长感、长线目标 |

**变现嵌入原则**：广告/付费应嵌入循环的「奖励放大」节点，而非打断循环。

---

## 1. 消除类：观察 → 选择 → 反馈 → 奖励 → 解锁

### 微循环（30 秒）
- **观察**：扫描棋盘，识别可消除组合
- **选择**：点击/滑动选定目标
- **反馈**：消除动画 + 音效 + 粒子 + 分数飘字（**爽感核心**）
- 设计要点：每次消除必须有视觉+听觉+震动三重反馈；连击/combo 加倍反馈强度

### 中循环（3-5 分钟）
- 完成一个关卡目标（消除 N 个红色 / 收集 X 个道具 / 达到分数）
- 步数限制制造紧张感
- 通关 → 星级评价（1-3 星）→ 奖励结算

### 宏循环（30 分钟+）
- **奖励**：通关获得金币/道具
- **解锁**：解锁新关卡、新地图、新玩法机制（每 10-20 关引入新元素）
- 章节/地图推进提供阶段性成就感

### 心流设计
- 难度曲线：每关难度增量 5%-10%，每 5 关一个难度峰值后回落
- 步数设计让玩家「差一步就赢」，激发重试

### 留存钩子
- 图鉴收集、隐藏关卡、每日挑战关、限时活动关

### 变现嵌入点
- 失败后「+5 步」看激励视频
- 通关奖励翻倍看激励视频
- 道具（锤子/刷新）看广告获取

---

## 2. 放置/挂机类：点击 → 积累 → 升级 → 解锁 → 转生

### 微循环（30 秒）
- **点击**：主动点击产生资源（早期）
- **积累**：数字增长 + 金币飞入动画
- 设计要点：数字跳动、暴击特效、点击音效是爽感来源

### 中循环（3-5 分钟）
- **升级**：用资源升级产出建筑/角色
- 每次升级 → 产出效率提升 → 数字增长加速
- 解锁自动化（离线挂机），从「点击」过渡到「管理」

### 宏循环（30 分钟+）
- **解锁**：新建筑、新角色、新地图、新功能
- **转生（Prestige）**：达到瓶颈 → 重置进度换取永久加成（钻石/灵魂）
- 转生是放置类的**核心长线驱动**，每次转生后成长速度更快

### 心流设计
- 升级成本指数增长（cost = base × 1.15^level），制造「再攒攒就能升」的期待
- 离线收益让玩家「不玩也在变强」，回归有惊喜

### 留存钩子
- 离线收益（回归即领）、转生里程碑、限时双倍活动、排行榜

### 变现嵌入点
- 离线收益翻倍看激励视频（**最高转化点**）
- 升级加速/跳过等待看广告
- 转生加成看广告

---

## 3. 合成类：拖拽 → 合成 → 升级 → 解锁 → 扩展

### 微循环（30 秒）
- **拖拽**：拖动两个相同物体靠近
- **合成**：合并动画 + 升级特效 + 新物体出现
- 设计要点：合成的「啵」一声 + 物体变大/变精致是核心爽感

### 中循环（3-5 分钟）
- **升级**：合成链推进（Lv1→Lv2→...→LvN）
- 完成订单/任务（提交特定等级物体换取奖励）
- 棋盘空间管理（格子不够用的策略性）

### 宏循环（30 分钟+）
- **解锁**：新合成链、新地块、新建筑
- **扩展**：地图扩张、装饰解锁、新区域开放
- Merge 经营类：合成 → 产出材料 → 建造/装修 → 推进剧情

### 心流设计
- 合成发现感：让玩家自己「试出来」高级合成，惊喜驱动
- 空间压力 → 释放节奏：满了→合成→腾出空间→满足

### 留存钩子
- 图鉴收集、装饰解锁、剧情推进、每日订单

### 变现嵌入点
- 补充体力/能量看激励视频
- 加速产出看广告
- 棋盘扩展/特殊合成看广告

---

## 4. 模拟经营：建造 → 产出 → 升级 → 扩展 → 装饰

### 微循环（30 秒）
- **建造**：放置建筑/设施
- **产出**：建筑自动产出资源，点击收集（金币飞入）
- 设计要点：收集时的连续点击 + 数字累加是即时满足

### 中循环（3-5 分钟）
- **升级**：升级建筑提升产出/解锁新产品
- 完成顾客订单/任务链
- 资源循环：原料 → 加工 → 成品 → 出售 → 金币

### 宏循环（30 分钟+）
- **扩展**：解锁新区域、新建筑类型、新玩法（如开放餐厅二楼）
- **装饰**：用赚的钱美化店铺/城市（自由度 + 个性化）
- 章节剧情推进

### 心流设计
- 多线并行目标：同时有 3-5 个进行中的建造/订单，玩家永远有事做
- 等待时间设计：短任务即时完成，长任务离线进行

### 留存钩子
- 装饰收集、店铺评级、好友互访、限时活动建筑

### 变现嵌入点
- 加速建造/生产看激励视频
- 离线收益翻倍
- 限定装饰/建筑（付费或看广告）

---

## 5. 卡牌/策略：收集 → 编队 → 战斗 → 奖励 → 收集

### 微循环（30 秒）
- **战斗**：单回合/单波次的技能释放、伤害数字、击败特效
- 设计要点：技能动画 + 暴击数字 + 连携技是爽感核心

### 中循环（3-5 分钟）
- **编队**：选择卡牌/英雄搭配阵容（策略深度）
- 完成一场战斗（推图/挑战/竞技场）
- 战斗结算 → 掉落奖励

### 宏循环（30 分钟+）
- **收集**：随机抽取/掉落获得新卡牌
- **养成**：升级、突破、装备、技能升级
- 推进主线章节、解锁新玩法（公会/竞技场/Roguelike）
- **闭环**：收集 → 变强 → 打更难关卡 → 收集更好卡

### 心流设计
- Build 多样性：让玩家尝试不同流派（速攻/控制/坦克）
- Roguelike 随机性：每局不同的卡牌/事件，重玩价值

### 留存钩子
- 卡牌图鉴、竞技场排名、公会战、赛季重置、限定卡池

### 变现嵌入点
- 随机抽取（付费核心）
- 体力恢复看激励视频
- 战斗奖励翻倍、复活看广告

---

## 6. 动作/跑酷：跑 → 躲 → 收集 → 加速 → 挑战

### 微循环（30 秒）
- **跑**：角色自动/手动前进
- **躲**：滑动/跳跃躲避障碍（操作反馈）
- **收集**：吃金币/道具（连续收集的音效叠加）
- 设计要点：操作手感（响应延迟 < 100ms）是生死线

### 中循环（3-5 分钟）
- 单局跑酷：从起点到终点 / 直到失败
- **加速**：吃到加速道具/进入冲刺段，节奏变化
- 结算：距离 + 金币 + 评分

### 宏循环（30 分钟+）
- **挑战**：刷新个人纪录、超越好友
- 解锁新角色/皮肤/坐骑（属性 + 外观）
- 解锁新地图/新模式

### 心流设计
- 速度渐进：单局内速度逐渐加快，紧张感递增
- 「差一点就破纪录」是最强重试驱动

### 留存钩子
- 好友排行榜（微信关系链）、每日挑战、皮肤收集、赛季排名

### 变现嵌入点
- 复活/续命看激励视频（**核心变现点**）
- 结算金币翻倍
- 皮肤试用/解锁看广告

## 7. 跨品类通用设计原则

### 7.1 反馈三要素
每个玩家操作必须在 **100ms 内**给出反馈：
1. **视觉**：动画/粒子/数字飘字
2. **听觉**：音效/BGM 变化
3. **触觉**：震动（wx.vibrateShort）

### 7.2 循环嵌套
微循环 → 中循环 → 宏循环必须**无缝嵌套**：
- 每次微循环产出推进中循环
- 每次中循环产出推进宏循环
- 玩家在任何时刻都知道「下一步做什么」

### 7.3 变现不破坏循环
- ❌ 强制弹窗打断循环
- ✅ 在循环奖励节点提供「看广告翻倍」的**可选**加速

### 7.4 首次循环必须在 60 秒内完成
玩家打开游戏 → 60 秒内必须体验到至少一次完整微循环的爽感（详见 ftue-design.md）。
