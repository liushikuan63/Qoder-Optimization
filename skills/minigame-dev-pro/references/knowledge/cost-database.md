# 微信小游戏成本数据库

> **使用说明**
> - 本文件所有金额均为**参考区间**，受地区、服务商、政策变化影响，**实际支出前请二次询价**。
> - 个人开发者与企业开发者合规路径不同，成本结构差异巨大，请先确认主体类型。
> - 数据基准：**2026 年**，政策类费用以官方最新公告为准。

---

|------|---------|---------|------|
| 软件著作权（软著） | 800-1500 元 | ✅ 必需 | 自助申请官费 0 元，但流程长（2-3 个月）；代办加急 800-3000 元 |
| ICP 备案 | 0 元 | ✅ 必需 | 通过云服务商（云服务商/腾讯云）免费代办，需域名（域名 50-100 元/年） |

## 5. 隐藏成本（最容易被忽视）

| 类型 | 估算 | 说明 |
|------|------|------|
| **时间成本** | 个人 3-6 个月全职 | 按机会工资折算，常被低估为「0 元」 |
| **学习成本** | 1-3 个月 | 引擎/合规/买量/数据分析新领域 |
| **机会成本** | 视个人情况 | 同期可做的其他项目收益 |
| **试错成本** | 50%-80% 项目失败 | 第一款大概率不赚钱，按学费心态预算 |
| **合规返工成本** | 1-4 周 | 审核被拒/资质补正 |
| **维护长尾成本** | 持续 | 即使停更也需服务器/客服基本支出 |

## 6. ROI 计算模型

### 6.1 基础公式

```
净利润 = 总收入 - 总成本
总收入 = DAU × 人均广告展示次数 × eCPM / 1000 × 30天 + 内购流水 × (1 - 渠道分成)
总成本 = 启动成本 + 月运营成本 × 生命周期月数 + 买量成本
```

### 6.2 广告变现简化模型（个人开发者）

```
月广告收入 ≈ DAU × 人均激励视频次数 × eCPM / 1000 × 30
```

**示例**（需实时验证 eCPM）：
- DAU = 5000，人均看 3 次激励视频，eCPM = 100 元
- 月收入 ≈ 5000 × 3 × 100 / 1000 × 30 = **45,000 元/月**
- ⚠️ 以上为纯公式计算示例，仅用于演示计算逻辑，**不构成任何收益承诺**，实际收入以真实运营数据为准

### 6.3 回本周期估算

```
回本月数 = 总启动成本 / (月收入 - 月运营成本)
```

**健康基准**：
- 回本周期 < 3 个月：优秀
- 回本周期 3-6 个月：健康
- 回本周期 > 12 个月：高风险，需重新评估

### 6.4 买量 ROI（LTV/CAC）

```
LTV（用户生命周期价值）= ARPDAU × 平均生命周期天数
CAC（获客成本）= 买量花费 / 新增用户数
健康线：LTV / CAC > 1.3（含自然量加成可放宽至 1.1）
```

## 7. 不同预算级别的可行方案

### 7.1 预算 0 元（极致零成本）
- **可行品类**：文字/剧情、轻量解谜、合成
- **路径**：软著自助申请（等 2-3 月）+ 全免费素材 + 微信云开发免费额度 + 自然流量
- **限制**：上线慢、美术弱、无买量、靠内容/创意突围
- **现实预期**：练手项目，月入 0-3000 元

### 7.2 预算 1000 元
- **可行品类**：合成、解谜、跑酷
- **路径**：软著代办（800）+ 少量素材（100）
- **加成**：上线提速 1-2 月，美术及格
- **现实预期**：月入 0-1 万（看创意与运气）

### 7.3 预算 5000 元
- **可行品类**：放置、塔防、模拟经营轻量版
- **路径**：软著加急（1500）+ 美术外包关键素材（2000）+ 音效（500）+ 小额买量测试（1000）
- **加成**：品质达到市场中位，可跑数据验证
- **现实预期**：月入 0.5-3 万（爆款概率提升）

### 7.4 预算 1 万元
- **可行品类**：除社交/重度外的多数品类
- **路径**：合规全套（2000）+ 美术整包（5000）+ 音效（1000）+ 买量测试（2000）
- **加成**：完整商业化闭环，可迭代
- **现实预期**：月入 1-5 万（需持续运营）

### 7.5 预算 5 万元
- **可行品类**：全品类（含轻量内购，需评估版号）
- **路径**：合规（含部分版号准备 1-2 万）+ 高品质美术（2 万）+ 服务器/SDK（5000）+ 买量（1-2 万）
- **加成**：接近小团队品质，可考虑小团队组队
- **现实预期**：月入 3-15 万（需专业能力 + 运气）

## 8. 成本控制红线

1. **不要在 MVP 阶段买量**：先验证次留 ≥ 30% 再投放。
2. **不要一次性投入全部预算**：分阶段（合规→开发→测试→买量）释放。
3. **不要为「显得专业」过度外包美术**：核心循环未验证前，美术够用即可。
4. **不要忽视时间成本**：把全职时间折算成工资计入成本，避免自我欺骗。
5. **版号决策要前置**：是否做内购在立项时就定，避免后期补办数十万。
