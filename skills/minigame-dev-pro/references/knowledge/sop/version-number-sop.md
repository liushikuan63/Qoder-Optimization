# 版号申请操作手册（企业）

> 适用：企业开发者（个人开发者无法申请）
> 操作平台：游戏出版主管部门
> 费用：申请免费，但准备成本数万至数十万元
> 周期：6个月-2年
> 最后更新：2026-07-09
> 最后核实：2026-08-03 ✓（已核实：内容与现行规则一致）
> 核实周期：每年（版号政策稳定，低频核实即可）
> 下次核实：2027-08-03

---

## 一、什么游戏需要版号

### 1.1 必须有版号的情况

| 变现/功能模式 | 是否需要版号 | 说明 |
|--------------|-------------|------|
| 含内购（用户充值买道具/货币） | 必须 | 这是最核心的判断标准 |
| 含付费下载 | 必须 | 用户花钱才能玩 |
| 含订阅/会员 | 必须 | 付费解锁内容 |
| 含竞技+付费 | 必须 | 如付费买皮肤、英雄 |
| 含联机+付费 | 必须 | 如MMO、联机对战+内购 |
| 含排行榜+付费 | 必须 | 付费影响排名 |
| 含随机抽取（付费） | 必须 | 花钱抽角色/道具 |

### 1.2 不需要版号的情况

| 变现/功能模式 | 是否需要版号 | 说明 |
|--------------|-------------|------|
| 纯广告变现（无任何内购） | 不需要 | 目前政策下不强制要求 |
| 完全免费+无广告 | 不需要 | 纯公益/展示类 |
| 纯单机+无联网+无付费 | 不需要 | 极简小游戏 |

### 1.3 高风险情形（须以监管规定为准）

| 情况 | 合规判定 | 建议 |
|------|------|------|
| 免费游戏+广告+轻度内购（去广告） | "去广告"付费属于内购，需版号 | 按内购处理，先取得版号 |
| 免费游戏+打赏 | 打赏金额大且影响游戏，有合规风险 | 咨询法务/主管部门确认 |
| 免费游戏+实物奖品活动 | 不涉及虚拟货币，通常不构成内购 | 活动规则需符合平台规范 |

**核心判断标准：用户是否需要花钱才能获得/影响游戏体验。是→需要版号。**

## 二、申请路径

### 2.1 整体流程

```
企业准备材料
    ↓
找有出版资质的代理单位（出版社/出版公司）
    ↓
代理单位进行内容审查和修改指导
    ↓
代理单位向省级新闻出版局提交申请
    ↓
省级新闻出版局初审（1-3个月）
    ↓
初审通过 → 报送出版主管部门
    ↓
出版主管部门终审（3-12个月）
    ↓
获得版号（国新出审[2026]XXXX号）
```

### 2.2 为什么需要代理单位

- 个人/普通企业没有"出版资质"，不能直接向新闻出版署提交
- 必须通过持有《网络出版服务许可证》的单位代为申报
- 这类单位通常是：出版社、有出版资质的游戏公司、专业代理机构
- 代理费用：通常3万-15万元（含内容审查、材料整理、申报服务）

### 2.3 找代理单位的渠道

1. 游戏出版主管部门官网查询持有《网络出版服务许可证》的单位名单
2. 行业内推荐（游戏行业社群、展会）
3. 专业代理机构（搜索"游戏版号代理"）
4. 大型游戏公司自有出版资质（如腾讯、网易等，但不对外）

**选择代理的注意事项：**
- 确认对方持有有效的《网络出版服务许可证》
- 确认有成功申报案例
- 合同中明确：费用、周期、失败退款条款
- 警惕声称保证通过审核的中介服务

## 三、需要准备的材料

### 3.1 企业资质材料

| 序号 | 材料 | 要求 |
|------|------|------|
| 1 | 营业执照副本 | 经营范围含"游戏开发"或"软件开发" |
| 2 | ICP许可证（增值电信业务经营许可证） | 注意：是许可证，不是ICP备案！ |
| 3 | 法人身份证 | 正反面 |
| 4 | 企业基本情况介绍 | 含团队、技术能力说明 |
| 5 | 游戏运营方案 | 运营计划、用户服务方案 |

### 3.2 游戏内容材料

| 序号 | 材料 | 要求 |
|------|------|------|
| 1 | 游戏完整版本 | 可完整体验，无重大BUG |
| 2 | 游戏安装包/体验地址 | 供审核人员实际体验 |
| 3 | 游戏脚本/剧情文本 | 全部文字内容（对话、描述、公告等） |
| 4 | 游戏截图 | 20张以上，覆盖所有功能界面 |
| 5 | 游戏宣传视频 | 3-5分钟，展示核心玩法 |
| 6 | 游戏说明书 | 玩法说明、操作指南 |
| 7 | 防沉迷系统说明 | 截图+文字说明已接入 |
| 8 | 实名认证系统说明 | 截图+文字说明 |
| 9 | 付费系统说明 | 所有付费点、价格、概率 |
| 10 | 概率公示截图 | 如有随机抽取 |

### 3.3 合规材料

| 序号 | 材料 | 要求 |
|------|------|------|
| 1 | 游戏自审报告 | 企业盖章 |
| 2 | 内容审查意见 | 代理单位出具 |
| 3 | 出版合同 | 与代理单位签订 |
| 4 | 著作权证明 | 软著证书 |
| 5 | 用户协议和隐私政策 | 完整文本 |
| 6 | 未成年人保护方案 | 防沉迷+付费限制+家长监护 |

### 3.4 ICP许可证办理（前置条件）

版号申请需要ICP许可证（不是ICP备案），办理路径：
1. 登录工业和信息化部政务服务平台 备案系统
2. 选择"增值电信业务经营许可证" → "在线办理"
3. 选择业务类型："信息服务业务（仅限互联网信息服务）"即ICP证
4. 填写企业信息、网站/应用信息
5. 上传材料：营业执照、法人身份证、股东证明、技术人员证明
6. 提交 → 管局审核（40-60个工作日）
7. 费用：免费（官费）

> ICP许可证要求：企业注册资本≥100万元（认缴即可）。

## 四、费用明细

| 项目 | 费用范围 | 说明 |
|------|----------|------|
| 版号申请官费 | 0元 | 行政审批不收费 |
| 代理服务费 | 3万-15万元 | 含材料整理、内容审查、申报 |
| ICP许可证办理 | 0元（自办）/ 5000-2万（代办） | 前置条件 |
| 游戏合规整改 | 1万-10万元 | 根据审核意见修改游戏 |
| 法律咨询 | 5000-3万元 | 合规审查、合同审核 |
| 测试费用 | 5000-2万元 | 确保无BUG |
| 时间成本 | 6个月-2年 | 团队等待期的人力成本 |
| **总计（典型）** | **5万-30万元** | 视游戏复杂度和代理选择 |

## 五、周期说明

### 5.1 各阶段时间

| 阶段 | 时间 | 说明 |
|------|------|------|
| 材料准备 | 1-3个月 | 含ICP许可证办理时间 |
| 代理审查+修改 | 1-3个月 | 代理提出修改意见，企业修改 |
| 省局初审 | 1-3个月 | 各省速度不同 |
| 总署终审 | 3-12个月 | 排队+审查 |
| **总计** | **6个月-2年** | 顺利的话6-9个月，不顺利可能2年+ |

### 5.2 影响周期的因素

- 游戏内容复杂度（越复杂审查越久）
- 是否需要多轮修改（每轮+1-2个月）
- 当月申报数量（排队）
- 政策窗口期（有时暂停审批）
- 代理单位的经验和效率

### 5.3 近年国产网络游戏版号发放情况

| 年份 | 月均发放量（国产） | 说明 |
|------|-----------|------|
| 2023 | 约70-90个/月 | 审批节奏逐步恢复 |
| 2024 | 约110-120个/月 | 全年发放量明显回升 |
| 2025 | 约140个/月（全年约1676个） | 供给进一步放宽 |
| 2026（截至7月） | 约130-197个/月 | 节奏加快，以当月公示为准 |

> 注：以上为国产游戏版号（进口版号另行审批，数量少得多）；手游/小游戏在国产版号中占比约60-70%。实际发放数以国家新闻出版署每月公示为准。

## 六、现实难度说明

### 6.1 对小游戏开发者的现实

**坦率地说：对于大多数微信小游戏开发者，版号不是现实选项。**

原因：
1. **周期太长**：6个月-2年，小游戏生命周期通常只有几个月
2. **费用太高**：5万-30万，大多数小游戏赚不回来
3. **门槛太高**：需要ICP许可证（注册资本100万+）、出版资质代理
4. **不确定性大**：不保证通过，可能反复修改
5. **个人不可申请**：必须是企业

### 6.2 版号审批的常见拒绝/修改原因

| 原因 | 说明 |
|------|------|
| 内容含违规表现 | 需要修改美术表现 |
| 付费设计不合理 | 随机抽取概率过低、付费点过多 |
| 防沉迷不完善 | 需要补充 |
| 游戏完成度不够 | 有BUG、功能缺失 |
| 文字内容有问题 | 涉及敏感词汇/历史 |
| 材料不齐全 | 需要补充 |
| 与已获批游戏过于相似 | 可能被质疑抄袭 |

### 6.3 什么情况下值得申请版号

- 游戏有长期运营计划（1年以上）
- 内购收入预期能覆盖版号成本（至少50万+年收入）
- 企业有充足资金和耐心
- 游戏品质高、内容合规、完成度好
- 有竞技/社交/联机元素，纯广告变现不够

## 七、替代方案（重点）

### 7.1 纯广告变现（最常用）

**不需要版号。这是绝大多数微信小游戏的选择。**

实现方式：
- 激励视频广告（看广告得奖励）
- 插屏广告（关卡间展示）
- Banner广告（底部/顶部横幅）
- 格子广告（非核心页面）

限制：
- 不能有任何内购（包括"去广告"付费）
- 收入取决于DAU和eCPM
- 适合休闲/超休闲游戏

### 7.2 先广告后版号

- 第一阶段：纯广告变现上线，验证市场
- 第二阶段：如果数据好，再申请版号加入内购
- 优点：降低风险，先验证再投入
- 缺点：需要重新提审，用户可能流失

### 7.3 含内购必须取得版号

- 含内购（含"去广告"付费）的游戏必须取得版号，不存在合规的替代路径
- 任何以"技术服务费""会员费"等名义收取用户费用以换取游戏内权益的做法，均可能被认定为内购
- 未取得版号即提供内购，将面临下架、处罚等后果

### 7.4 海外发行

- 海外不需要中国版号
- 但微信小游戏主要面向国内用户
- 如果做出海，可以考虑其他平台

│   │   │
│   │   ├── 预算充足 + 长期运营计划？

## 九、常见问题

**Q: 微信审核时会检查版号吗？**
A: 会。如果游戏有内购功能，微信审核时会要求提供版号。没有版号+有内购=审核不通过。

**Q: 版号未取得时能提审吗？**
A: 不可以。必须取得版号后才能提审，无其他路径。

**Q: 版号与游戏名称绑定吗？**
A: 是的。获得版号后游戏不能改名，改名需要重新申请。

**Q: 版号有有效期吗？**
A: 没有。一次获得永久有效（除非被撤销）。

**Q: 一个版号能用于多个游戏吗？**
A: 不能。一个版号对应一个游戏。

**Q: 个人开发者真的完全不能申请吗？**
A: 是的。版号申请主体必须是企业+有出版资质的单位。个人无解。

**Q: "去广告"付费算内购吗？**
A: 属于内购。任何向用户收取费用以获取游戏内权益（包括去除广告）的行为，均应按内购处理并取得版号。建议开发者按此标准执行，避免合规风险。
