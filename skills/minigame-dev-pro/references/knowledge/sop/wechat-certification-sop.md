# 微信认证操作手册（企业）

> 适用：企业开发者（个人开发者无需微信认证）
> 操作平台：微信公众平台（PC浏览器）
> 费用：300元/年
> 周期：1-5个工作日
> 最后更新：2026-07-09
> 最后核实：2026-08-03 ✓（已核实：内容与现行规则一致）
> 核实周期：每半年（微信认证规则中等频率变动）
> 下次核实：2027-02-03

---

## 一、什么是微信认证

微信认证是微信公众平台对企业主体的身份真实性审核。通过认证后：
- 小游戏名称旁显示认证标识（增加用户信任）
- 解锁更多高级接口能力
- 支持微信支付（内购必须）
- 支持更多广告组件
- 名称保护（认证后名称受保护，他人不能注册同名）

**个人开发者不需要也不能做微信认证，个人主体通过身份证验证即可。**

---

## 二、操作路径

### 步骤1：登录微信公众平台

1. 打开 微信公众平台
2. 使用管理员微信扫码登录
3. 确认进入的是企业主体的小游戏后台

### 步骤2：进入认证页面

1. 左侧菜单 →「设置」
2. 顶部Tab →「基本设置」
3. 找到「微信认证」区域
4. 点击「开始认证」（首次）或「续费认证」（已认证过期）

> 也可以从：左侧菜单 →「设置」→「微信认证」直接进入

### 步骤3：确认主体信息

系统会自动显示注册时填写的企业信息：
- 企业名称
- 统一社会信用代码
- 法人姓名
- 注册地址

**检查所有信息是否与当前营业执照一致。如有变更，需先做主体信息变更。**

### 步骤4：选择认证类型

- 选择「企业认证」
- 确认认证费用：300元/年

### 步骤5：填写认证资料

| 字段 | 填写内容 | 注意事项 |
|------|----------|----------|
| 企业名称 | 营业执照全称 | 自动填充，核对即可 |
| 营业执照注册号 | 统一社会信用代码 | 18位 |
| 营业执照照片 | 上传执照副本照片 | 清晰、完整、在有效期内 |
| 法人姓名 | 法人身份证上的姓名 | |
| 法人身份证号 | 18位身份证号 | |
| 法人身份证照片 | 正面+反面 | 清晰、未过期 |
| 运营者姓名 | 实际操作人 | 可以是法人或授权员工 |
| 运营者身份证号 | 运营者身份证号 | |
| 运营者手机号 | 运营者手机号 | 用于接收审核电话 |
| 对公账户信息 | 开户行+账号 | 用于打款验证 |
| 认证公函 | 下载模板→填写→盖章→上传 | 见下方说明 |

### 步骤6：认证公函

1. 系统提供公函模板下载（PDF/Word）
2. 打印公函
3. 填写：
   - 企业名称
   - 认证账号名称
   - 运营者姓名和身份证号
   - 声明授权该运营者管理此账号
4. 法人签字（手写）
5. 加盖公司公章（红色圆章）
6. 扫描/拍照上传

### 步骤7：支付认证费

1. 确认资料无误后 →「提交并支付」
2. 支付方式：
   - 微信支付（扫码支付300元）
   - 对公转账（转账到指定账户，备注认证订单号）
3. 支付成功后进入审核流程

### 步骤8：等待审核

审核方式（可能同时进行）：

**方式A：对公打款验证**
- 微信向你的对公账户打入一笔随机小额款项（如0.01-0.99元）
- 你在后台填写收到的具体金额
- 金额正确 → 验证通过
- 注意：收到打款后必须在10天内填写金额，超时需重新发起

**方式B：法人扫码验证**
- 系统生成二维码
- 法人用微信扫码确认身份
- 法人微信实名信息必须与填写的法人信息一致

**方式C：电话核实**
- 审核员可能拨打运营者手机号
- 确认企业信息、认证意愿
- 注意接听陌生来电（可能是0755/010开头）

### 步骤9：认证完成

- 审核通过 → 后台显示"已认证"
- 认证有效期：1年（从通过之日起）
- 到期前30天会提醒续费
- 认证标识出现在小游戏资料页

## 三、需要准备的材料清单

| 序号 | 材料 | 要求 | 准备时间 |
|------|------|------|----------|
| 1 | 营业执照副本 | 原件拍照/扫描，在有效期内 | 即时 |
| 2 | 法人身份证正反面 | 清晰照片，未过期 | 即时 |
| 3 | 运营者身份证正反面 | 如非法人本人操作 | 即时 |
| 4 | 对公银行账户信息 | 开户行全称+账号 | 找财务确认 |
| 5 | 认证公函（盖章） | 下载模板→打印→签字→盖章→扫描 | 1-2天 |
| 6 | 300元认证费 | 微信支付或对公转账 | 即时 |
| 7 | 法人配合 | 可能需要法人扫码或接听电话 | 提前沟通 |

## 四、费用说明

| 项目 | 费用 | 说明 |
|------|------|------|
| 首次认证 | 300元 | 一次性 |
| 年度续费 | 300元/年 | 每年到期前续费 |
| 认证失败重新提交 | 不再收费 | 同一订单内可免费重交 |
| 变更认证（改名等） | 300元 | 视为新认证 |

> 300元是微信官方收取的审核服务费，无论认证是否通过都不退还。
> 但认证失败后可以免费修改资料重新提交（同一订单内）。

## 五、认证流程和时间

```
Day 0: 准备材料（营业执照、身份证、公函盖章）
Day 1: 登录后台 → 填写资料 → 上传材料 → 支付300元
Day 1-2: 微信初审（资料格式检查）
Day 2-3: 对公打款 / 法人扫码验证
Day 3-5: 审核员电话核实（如有）
Day 5: 认证通过（最快1天，最慢5个工作日）
```

**通常时间线：**
- 最快：1个工作日（材料齐全+法人秒扫码）
- 一般：2-3个工作日
- 最慢：5个工作日（遇到节假日顺延）

## 六、认证失败处理

### 失败原因1：营业执照问题
- 执照过期/被吊销
- 照片不清晰
- 信息与填写不一致
- **处理**：更新执照/重新拍照/核对信息后重新提交

### 失败原因2：对公打款验证失败
- 填写金额错误
- 超过10天未填写
- 账户已注销
- **处理**：重新发起打款验证，注意及时查看银行流水

### 失败原因3：法人验证失败
- 法人微信未实名
- 法人微信实名信息与填写不一致
- 法人未在规定时间内扫码
- **处理**：确认法人微信已实名且信息一致，重新生成二维码

### 失败原因4：公函问题
- 未盖公章（盖了合同章/财务章）
- 法人未签字
- 公函信息与后台填写不一致
- **处理**：重新下载模板，正确填写并盖公章

### 失败原因5：电话核实未通过
- 运营者未接听电话
- 回答信息与提交资料不一致
- **处理**：保持电话畅通，如实回答

### 失败后重新提交：
1. 后台会显示失败原因
2. 点击「修改资料」
3. 根据失败原因修改对应项
4. 重新提交（同一订单内不需要再付300元）
5. 重新进入审核流程

## 七、认证到期续费

### 续费时间
- 认证有效期1年
- 到期前30天：后台顶部出现续费提醒横幅
- 到期前7天：管理员微信收到模板消息提醒
- 到期当天：如未续费，认证失效

### 续费操作
1. 登录后台 →「设置」→「微信认证」
2. 点击「续费认证」
3. 确认企业信息（如有变更先更新）
4. 支付300元
5. 等待审核（通常1-2天，比首次快）

### 认证过期的后果
- 认证标识消失
- 微信支付能力被暂停（内购不可用）
- 部分高级接口不可用
- 名称保护失效（他人可能注册同名）
- 续费后恢复（不需要重新注册）

## 八、常见坑点

| 序号 | 坑点 | 说明 |
|------|------|------|
| 1 | 对公账户是新开的 | 新开户可能需要几天才能收款，提前确认 |
| 2 | 法人出国/联系不上 | 提前确认法人可以配合扫码或接电话 |
| 3 | 营业执照刚变更 | 变更后需要等工商信息同步（3-7天）再认证 |
| 4 | 运营者离职 | 认证后运营者可以变更，但需要重新验证 |
| 5 | 忘记续费 | 设置日历提醒，到期前30天处理 |
| 6 | 公函用错章 | 必须是公司行政公章（圆章），不是合同章 |
| 7 | 打款金额看错 | 注意是"分"还是"元"，如收到0.37元就填0.37 |
| 8 | 多个账号认证 | 同一企业多个小游戏需要分别认证，每个300元 |

## 九、认证后能做什么

认证通过后解锁的能力：

| 能力 | 未认证 | 已认证 |
|------|--------|--------|
| 微信支付（内购） | 不可用 | 可用 |
| 认证标识 | 无 | 有（增加信任） |
| 名称保护 | 无 | 有 |
| 获取用户UnionID | 不可用 | 可用 |
| 部分广告组件 | 受限 | 完整可用 |
| 小程序跳转 | 受限 | 可用 |
| 附近的小程序 | 不可用 | 可用 |
