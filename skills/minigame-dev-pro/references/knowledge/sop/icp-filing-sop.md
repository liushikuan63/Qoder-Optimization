# ICP备案逐步操作手册

> 适用：个人开发者 / 企业开发者
> 操作平台：微信公众平台（PC浏览器）
> 费用：免费
> 周期：7-20个工作日
> 最后更新：2026-07-09
> 最后核实：2026-08-03 ✓（已核实：内容与现行规则一致）
> 核实周期：每半年（管局备案政策中等频率变动）
> 下次核实：2027-02-03

---

## 一、前置条件

在开始ICP备案之前，你必须已经拥有以下全部条件：

| 序号 | 前置项 | 说明 |
|------|--------|------|
| 1 | 已注册小游戏账号 | 在 微信公众平台 注册，选择"小游戏"类型 |
| 2 | 已完成主体认证 | 个人：身份证验证；企业：对公打款验证或法人扫码 |
| 3 | 已确定小游戏名称 | 备案后改名需要重新备案，所以先想好名字 |
| 4 | 准备好证件照片 | 见下方"材料准备" |
| 5 | 一个能接收短信的手机号 | 管局审核时会发短信验证码 |

### 材料准备

**个人开发者：**
- 身份证正面照片（清晰、完整、无遮挡、未过期）
- 身份证反面照片（国徽面）
- 负责人手持身份证照片（正面，能看清人脸和证件信息）
- 手机号（必须是负责人本人的）

**企业开发者：**
- 营业执照副本照片（清晰、完整、在有效期内）
- 法人身份证正反面照片
- 网站负责人身份证正反面照片（如果负责人不是法人，还需要授权书）
- 负责人手持身份证照片
- 法人授权书（如负责人非法人本人）
- 手机号（负责人本人的）

### 照片要求（通用）
- 格式：JPG/PNG
- 大小：每张不超过5MB
- 清晰度：文字可辨认，人脸可识别
- 不能是翻拍（不能拍屏幕上的照片）
- 不能有水印、遮挡、反光
- 证件必须在有效期内

## 二、操作路径

### 步骤1：登录微信公众平台

1. 打开浏览器（推荐Chrome），访问 微信公众平台
2. 使用小游戏管理员微信扫码登录
3. 确认进入的是你的小游戏管理后台（左上角显示小游戏名称）

### 步骤2：进入备案页面

1. 左侧菜单栏 → 点击「设置」
2. 在设置页面顶部Tab栏 → 点击「基本设置」
3. 向下滚动找到「小程序备案」区域
4. 点击「开始备案」按钮（首次）或「变更备案」（已有备案需修改）

> 如果找不到"小程序备案"入口，确认：
> - 账号已完成主体认证
> - 使用的是管理员账号登录（非运营者）
> - 浏览器清除了缓存

### 步骤3：填写主体信息

**个人主体：**

| 字段 | 填写内容 | 注意事项 |
|------|----------|----------|
| 主办单位名称 | 你的真实姓名 | 必须与身份证完全一致，不能用昵称 |
| 主办单位证件号 | 身份证号码 | 18位，末位X大写 |
| 主办单位证件住所 | 身份证上的地址 | 照抄身份证，不要写现居住地址 |
| 通讯地址 | 实际收件地址 | 用于接收管局信函（如有） |
| 负责人姓名 | 你的姓名 | 个人主体负责人必须是本人 |
| 负责人证件号 | 身份证号码 | 同上 |
| 负责人手机号 | 本人手机号 | 管局会发短信验证，必须能收到 |
| 应急联系电话 | 另一个手机号或座机 | 不能与主手机号相同 |
| 电子邮箱 | 常用邮箱 | 接收备案通知 |

**企业主体：**

| 字段 | 填写内容 | 注意事项 |
|------|----------|----------|
| 主办单位名称 | 营业执照上的公司全称 | 一字不差！"有限公司"≠"有限责任公司" |
| 主办单位证件号 | 统一社会信用代码（18位） | 营业执照右上角 |
| 主办单位证件住所 | 营业执照上的注册地址 | 照抄执照 |
| 通讯地址 | 实际办公地址 | 可以不同于注册地址 |
| 负责人姓名 | 法人或授权负责人 | 非法人需要授权书 |
| 负责人证件号 | 负责人身份证号 | |
| 负责人手机号 | 负责人本人手机号 | 管局短信验证 |
| 应急联系电话 | 公司座机或其他手机号 | |
| 电子邮箱 | 公司邮箱 | |

### 步骤4：填写小程序信息

| 字段 | 填写内容 | 注意事项 |
|------|----------|----------|
| 小程序名称 | 你的小游戏名称 | 必须与后台设置的小游戏名称完全一致 |
| 小程序ID | 自动填充（AppID） | 不用手动填 |
| 服务内容类型 | 选择「游戏」| 不要选"工具""社交"等其他类型 |
| 小程序简介 | 一句话描述游戏 | 如"一款休闲益智消除类游戏" |
| 前置审批 | 一般选"无" | 除非你有新闻/出版/医疗等特殊资质 |
| 备注 | 可留空 | 如有特殊情况说明 |

### 步骤5：上传材料

按系统提示逐项上传：

1. **主体证件**：身份证正反面 / 营业执照
2. **负责人证件**：负责人身份证正反面
3. **负责人手持证件照**：
   - 人像清晰，证件文字可读
   - 不能戴帽子、墨镜
   - 背景简洁（白墙为宜）
   - 证件不能遮挡脸部
4. **授权书**（企业，负责人非法人时）：
   - 使用系统提供的模板下载
   - 法人签字 + 公司公章
   - 写明授权事项和有效期

### 步骤6：确认提交

1. 预览所有填写信息（逐页检查）
2. 勾选"我已阅读并同意《备案服务协议》"
3. 点击「提交」
4. 系统提示"提交成功，等待平台初审"

### 步骤7：等待审核

审核分两个阶段：

**第一阶段：微信平台初审（1-2个工作日）**
- 微信团队检查材料完整性和格式
- 如有问题，会在后台显示"驳回"并给出原因
- 驳回后修改重新提交即可

**第二阶段：管局终审（7-20个工作日）**
- 初审通过后自动提交到对应省份的通信管理局
- 管局审核期间会发送短信验证码到负责人手机
- **收到短信后必须在24小时内完成验证**（点击短信中的链接，输入验证码）
- 逾期未验证 → 备案失败，需要重新提交

### 步骤8：备案通过

- 管局审核通过后，微信公众平台后台会显示"备案成功"
- 获得备案号（格式：粤ICP备2026XXXXXX号-1A）
- 备案号自动关联到小游戏，无需额外操作
- 此时可以正常提交小游戏审核上架

## 三、主体名称一致性要求（极重要）

这是备案被驳回的第一大原因：

| 场景 | 正确 | 错误 |
|------|------|------|
| 企业名称 | 深圳市开心游戏有限公司 | 深圳开心游戏有限公司（少了"市"） |
| 企业类型 | 有限责任公司 | 有限公司（执照写什么就填什么） |
| 个人姓名 | 张三丰 | 张三（身份证是三个字就写三个字） |
| 游戏名称 | 示例小游戏 | 示例小游戏V1.0（不要带版本号） |

**核心原则：所有名称必须与证件上的文字一字不差、一个标点不差。**

| 省份 | 通常周期 | 备注 |
|------|----------|------|
| 广东 | 7-10工作日 | 较快 |
| 北京 | 10-15工作日 | 中等 |
| 上海 | 10-15工作日 | 中等 |
| 浙江 | 7-12工作日 | 较快 |
| 四川 | 10-15工作日 | 中等 |
| 其他省份 | 10-20工作日 | 以实际为准 |

> 注意：工作日不含周末和法定节假日。遇到春节、国庆等长假会顺延。

**提速方法：** 没有官方提速通道。唯一能做的是确保材料一次通过，避免驳回重交浪费时间。

## 五、常见驳回原因和修复

### 驳回原因1：主体信息不一致
- 表现：公司名称与营业执照不完全一致
- 修复：对照营业执照逐字修改，注意"市""区""县"等行政区划不能省略

### 驳回原因2：证件照片不清晰
- 表现：身份证照片模糊、反光、有遮挡
- 修复：重新拍摄，光线充足、平铺拍摄、不戴手机壳

### 驳回原因3：手持证件照不合规
- 表现：证件遮挡脸部、照片模糊、非本人
- 修复：让他人帮忙拍摄，证件放在胸前不遮脸，对焦清晰

### 驳回原因4：服务内容类型选错
- 表现：游戏类小程序选了"工具"或"生活服务"
- 修复：服务内容类型改为"游戏"

### 驳回原因5：短信验证超时
- 表现：管局短信未在24小时内验证
- 修复：重新提交备案，注意保持手机畅通

### 驳回原因6：负责人手机号非本人
- 表现：手机号实名信息与负责人不一致
- 修复：使用负责人本人实名的手机号

### 驳回原因7：备案期间修改了小程序名称
- 表现：提交备案后在后台改了小游戏名字
- 修复：等备案通过后再改名，或撤销备案重新提交

### 驳回原因8：同一主体已有备案冲突
- 表现：该主体下已有其他小程序备案，信息不一致
- 修复：确保同一主体下所有备案信息一致（特别是联系方式）

## 七、备案后的注意事项

1. **不要随意修改主体信息**：公司更名、法人变更后需要在30天内做"变更备案"
2. **不要注销营业执照**：主体失效后备案会被管局注销，小游戏下架
3. **多个小程序共用主体信息**：同一主体下新增小程序备案时，主体信息必须与已有备案一致
4. **备案号展示**：小游戏"关于"页面建议展示备案号（非强制但推荐）
5. **年度核查**：部分省份管局会进行年度备案信息核查，收到通知后及时确认

## 八、操作时间线（建议）

```
Day 0:  确定小游戏名称，准备所有证件照片
Day 1:  登录公众平台，填写并提交备案
Day 2-3: 等待平台初审（如被驳回当天修改重交）
Day 4:  初审通过，进入管局审核
Day 5-25: 管局审核（注意接听电话、接收短信）
Day 25-30: 备案通过，获得备案号
Day 30+: 可以提交小游戏审核上架
```

> 建议在开发初期（写第一行代码时）就启动备案，因为周期长，不要等到游戏做完了才去备案。
