# 游戏内容备案手册（企业）

> 适用：企业开发者
> 操作平台：全国文化市场技术监管与服务平台 / 各地文化和旅游厅
> 费用：免费（行政备案不收费）
> 周期：1-3个月
> 最后更新：2026-07-09
> 最后核实：2026-08-03 ✓（已核实：内容与现行规则一致）
> 核实周期：每半年（游戏内容备案规则中等频率变动）
> 下次核实：2027-02-03

---

## 一、什么情况需要备案

### 1.1 必须备案的情况

| 情况 | 是否需要备案 | 说明 |
|------|-------------|------|
| 含UGC功能（用户聊天） | 必须 | 用户可以发送文字/语音消息 |
| 含UGC功能（自定义昵称） | 必须 | 用户可以自定义显示名称 |
| 含UGC功能（社区/论坛） | 必须 | 用户发帖、评论 |
| 含UGC功能（自定义内容） | 必须 | 如自定义地图、自定义角色 |
| 有虚拟货币/道具系统 | 必须 | 游戏内有经济系统 |
| 有联机/多人互动 | 建议备案 | 玩家之间有交互 |
| 有排行榜+社交功能 | 建议备案 | 涉及用户互动 |

### 1.2 不需要备案的情况

| 情况 | 是否需要备案 | 说明 |
|------|-------------|------|
| 纯单机游戏 | 不需要 | 无联网、无UGC |
| 纯广告变现+无社交 | 不需要 | 只有排行榜（微信提供）通常不需要 |
| 无用户输入功能 | 不需要 | 用户不能输入任何文字 |

### 1.3 判断原则

**核心标准：游戏中是否存在用户生成内容（UGC）或用户间交互。**
- 有 → 需要备案
- 没有 → 通常不需要

> 注意：各地执行标准可能有差异。如果不确定，建议电话咨询当地文化和旅游厅/局。

## 二、备案路径

### 2.1 主管部门

2019年机构改革后，游戏管理职能有所调整：
- **国家层面**：游戏出版主管部门主管游戏审批
- **地方层面**：部分省份的游戏运营备案仍由文化和旅游厅/局负责
- **实际操作**：以当地主管部门要求为准

### 2.2 备案平台

**线上平台：**
- 全国文化市场技术监管与服务平台：文化市场管理平台
- 部分省份有自己的备案系统（如广东、上海）

**线下渠道：**
- 企业注册所在地的省/市文化和旅游厅/局
- 电话咨询确认具体办理窗口和材料要求

### 2.3 操作步骤

#### 步骤1：确认当地要求

1. 搜索"XX省（你的注册地）网络游戏备案"
2. 访问当地文化和旅游厅官网
3. 查找"网络游戏管理"或"网络文化经营"相关栏目
4. 下载/查看备案指南和材料清单
5. 如有疑问，拨打咨询电话确认

> 各省要求可能略有不同，务必以当地最新要求为准。

#### 步骤2：注册平台账号

1. 访问 文化市场管理平台
2. 点击「注册」→ 选择「企业用户」
3. 填写：
   - 企业名称（与营业执照一致）
   - 统一社会信用代码
   - 法人姓名
   - 联系人姓名+手机号
   - 邮箱
4. 上传营业执照照片
5. 提交 → 等待平台审核（1-3个工作日）

#### 步骤3：填写备案信息

登录后 →「网络游戏备案」→「新增备案」

| 字段 | 填写内容 | 注意事项 |
|------|----------|----------|
| 游戏名称 | 与实际上线名称一致 | 不能与版号/软著名冲突 |
| 游戏类型 | 休闲/竞技/RPG/棋牌等 | 如实选择 |
| 运营单位 | 企业全称 | 与营业执照一致 |
| 运营单位地址 | 实际办公地址 | |
| 联系人 | 运营负责人 | |
| 联系电话 | 手机号+座机 | 审核时可能打电话 |
| 游戏简介 | 200-500字描述 | 含玩法、目标用户、变现方式 |
| 是否含UGC | 是/否 | 如实填写 |
| UGC类型 | 聊天/昵称/社区/自定义等 | 勾选所有适用的 |
| 是否有虚拟货币 | 是/否 | |
| 虚拟货币说明 | 获取方式、使用范围 | 如有则必填 |
| 是否有付费 | 是/否 | |
| 防沉迷说明 | 已接入/具体措施 | |
| 上线日期 | 实际或计划上线日期 | |
| 运营网址/平台 | 微信小游戏 | 填写平台名称 |

#### 步骤4：上传材料

| 序号 | 材料 | 要求 |
|------|------|------|
| 1 | 营业执照副本 | 扫描件，清晰完整 |
| 2 | ICP许可证或ICP备案截图 | 证明合法运营 |
| 3 | 版号证明（如有） | 有内购的必须提供 |
| 4 | 软著证书 | 扫描件 |
| 5 | 游戏截图 | 10张以上，覆盖主要界面 |
| 6 | 防沉迷系统截图 | 实名认证界面+限制提示界面 |
| 7 | 用户协议 | 完整文本 |
| 8 | 隐私政策 | 完整文本 |
| 9 | 虚拟货币/道具说明（如有） | 获取方式、使用规则 |
| 10 | 内容自审制度说明 | 企业如何审核UGC内容 |
| 11 | 技术安全措施说明 | 如何保障用户数据安全 |

#### 步骤5：提交并等待

1. 预览所有信息 → 确认无误
2. 点击「提交」
3. 状态变为"待审核"
4. 等待审核（1-3个月）
5. 期间可能收到补正通知（补充材料或修改信息）
6. 审核通过 → 获得备案编号

#### 步骤6：备案通过

- 获得备案编号（格式因省份而异）
- 在游戏"关于"页面展示备案编号（建议）
- 保存备案凭证（电子/纸质）

## 三、需要准备的材料详解

### 3.1 游戏截图要求

至少10张，覆盖：
1. 游戏启动/加载画面
2. 登录界面
3. 主界面/大厅
4. 核心玩法画面（游戏进行中）
5. 设置界面
6. 商城/付费界面（如有）
7. 聊天/社交界面（如有）
8. 排行榜界面（如有）
9. 防沉迷提示界面
10. 隐私政策/用户协议界面

要求：
- 分辨率不低于1280x720
- 格式JPG/PNG
- 每张不超过5MB
- 能清晰看到界面内容

### 3.2 内容自审制度说明

如果游戏有UGC功能，必须说明你如何审核用户内容：

```
模板：

《[游戏名称]内容自审制度》

一、审核范围
本游戏涉及用户生成内容的功能包括：
- 用户自定义昵称
- [聊天/社区/其他]

二、审核机制
1. 技术过滤：
   - 在服务端/云函数接入微信内容安全接口：文本 security.msgSecCheck、图片 security.imgSecCheck（小游戏可选用"游戏内容安全"服务端接口 gamesecurity.mediaCheck）
   - 建立敏感词库（XX个词条），实时过滤
   - 图片内容经服务端内容安全接口审核

2. 人工审核：
   - 设置内容审核岗位（X人）
   - 每日巡查用户生成内容
   - 接到举报后2小时内处理

3. 处罚机制：
   - 首次违规：警告+删除内容
   - 二次违规：禁言24小时
   - 三次违规：永久封禁

三、投诉举报
- 游戏内设置"举报"按钮
- 举报处理时限：24小时
- 投诉邮箱：xxx@xxx.com

四、应急预案
- 发现严重违规内容立即下线
- 配合主管部门检查
- 保留相关日志不少于60天
```

### 3.3 虚拟货币说明（如有）

```
模板：

《[游戏名称]虚拟货币说明》

一、虚拟货币名称：[金币/钻石/积分]

二、获取方式：
- 游戏内免费获取：[完成关卡/每日签到/观看广告]
- 付费获取：[无 / 通过微信支付充值]

三、使用范围：
- [购买游戏内道具]
- [解锁关卡]
- 不可兑换为法定货币
- 不可在用户之间转让

四、退款规则：
- 未使用的付费虚拟货币可申请退款
- 退款通过微信原路返回
- 已使用的不予退还

五、有效期：
- 虚拟货币无有效期限制
- 账号注销后虚拟货币清零
```

## 四、周期说明

| 阶段 | 时间 | 说明 |
|------|------|------|
| 材料准备 | 3-7天 | 截图、制度文件撰写 |
| 平台注册+审核 | 1-3天 | 账号审核 |
| 提交备案 | 1天 | 在线填写+上传 |
| 主管部门审核 | 1-3个月 | 各省速度不同 |
| 补正（如有） | +2-4周 | 补充材料后重新审核 |
| **总计** | **1-3个月** | 顺利的话1个月出头 |

### 影响周期的因素：
- 材料是否齐全（缺材料会退回补正）
- 当地主管部门工作量
- 游戏内容复杂度
- 是否涉及敏感类型（棋牌类审核更严）

## 六、备案后的义务

### 6.1 持续合规义务

| 义务 | 说明 |
|------|------|
| 内容变更备案 | 游戏内容重大更新（新增UGC功能、新增付费模式）需变更备案 |
| 年度报告 | 部分地区要求每年提交运营报告 |
| 配合检查 | 主管部门可能进行线上/线下检查 |
| 日志留存 | 用户行为日志保存不少于60天 |
| 投诉处理 | 建立投诉渠道，及时处理 |
| 信息变更 | 企业名称/地址/法人变更后30天内变更备案 |

### 6.2 违规后果

| 违规行为 | 后果 |
|----------|------|
| 未备案运营 | 责令整改 + 罚款1万-3万元 |
| 备案信息虚假 | 撤销备案 + 罚款 |
| 拒不整改 | 吊销相关许可 + 通知平台下架 |
| UGC内容违规（未审核） | 罚款 + 暂停运营 + 严重者刑事追责 |

## 七、常见坑点

| 序号 | 坑点 | 说明 |
|------|------|------|
| 1 | 不确定是否需要备案 | 有UGC就备，没有就不用。不确定就打电话问 |
| 2 | 各省要求不同 | 广东、上海、北京各有细则，以当地为准 |
| 3 | 上线后才想起备案 | 应在上线后30天内完成，超期有处罚风险 |
| 4 | 材料不齐全反复补正 | 第一次就按清单准备齐全 |
| 5 | 棋牌类游戏审核特别严 | 棋牌类可能被要求额外说明违规防范措施 |
| 6 | 游戏更新后忘记变更备案 | 新增UGC功能必须变更备案 |
| 7 | 没有内容审核机制 | 有UGC必须有审核制度+技术过滤 |
| 8 | 日志留存不够60天 | 服务器日志保存期限要满足要求 |
| 9 | 把备案和版号搞混 | 备案≠版号，两个是不同的事 |
| 10 | 机构改革后找不到对口部门 | 先打12345市民热线咨询转接 |

## 八、与其他合规项的关系

```
ICP备案（RULE-001）→ 所有小程序/小游戏必须 → 通信管理局
    ↓
软著（RULE-002）→ 提审必须 → 版权保护中心
    ↓
版号（RULE-006）→ 有内购必须 → 游戏出版主管部门
    ↓
内容备案（RULE-007）→ 有UGC/运营类 → 文旅部门/文化主管部门
    ↓
微信认证 → 企业必须 → 微信平台
    ↓
防沉迷（RULE-005）→ 所有游戏必须 → 微信平台+实名认证系统
```

**内容备案是独立于版号的另一项要求。有版号不代表不用备案，没版号也可能需要备案。**

## 九、快速判断清单

回答以下问题判断你是否需要内容备案：

- [ ] 你的游戏有聊天功能吗？→ 需要
- [ ] 你的游戏用户可以自定义昵称吗？→ 需要
- [ ] 你的游戏有社区/论坛/评论功能吗？→ 需要
- [ ] 你的游戏有用户自定义内容（地图/角色/文字）吗？→ 需要
- [ ] 你的游戏有虚拟货币/道具系统吗？→ 需要
- [ ] 你的游戏有联机/多人实时互动吗？→ 建议备案

如果以上全部为"否"→ 通常不需要内容备案。

## 十、操作时间线（建议）

```
上线前2个月: 确认是否需要备案（对照判断清单）
上线前1个月: 准备材料（截图、制度文件、说明文档）
上线前1周:  注册平台账号，预填备案信息
上线当天:   提交备案申请
上线后1-3个月: 等待审核，配合补正
获得备案编号: 在游戏"关于"页面展示
```

> 虽然规定是"上线后30天内"，但建议提前准备，上线即提交，避免超期风险。
