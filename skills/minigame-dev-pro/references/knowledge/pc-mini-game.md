# PC端小游戏经营指南

> 数据时效：2026-07（PC端小游戏为2025年微信新增长点，数据有限）
> 置信度：中（部分数据基于行业趋势推测，需验证）

---

## 一、PC端小游戏是什么

2025年微信开放 PC 端小游戏，用户可在 Windows/Mac 微信客户端直接玩小游戏。这是微信小游戏从"移动优先"向"全场景"扩展的关键一步。

### 核心特征

| 维度 | 移动端 | PC端 |
|------|--------|------|
| 屏幕尺寸 | 3.5-7英寸 | 13-27英寸 |
| 输入方式 | 触摸 | 键鼠 |
| 性能 | 受限（移动芯片） | 强劲（桌面CPU/GPU） |
| 时长 | 碎片化（5-15分钟） | 长时长（30分钟+） |
| ARPU | 中 | 高（付费意愿强） |
| 竞争 | 红海 | 蓝海（2026年） |

---

## 二、适配要求

### 屏幕适配

```
设计策略：
├── 窗口模式：默认 1280×720 窗口，可拉伸
├── 全屏模式：支持一键全屏切换
├── 分辨率自适应：按窗口尺寸缩放渲染
└── UI布局：大屏幕需重新设计布局（不能简单放大移动端UI）
```

### 键鼠交互

| 交互 | 移动端 | PC端 |
|------|--------|------|
| 点击 | touchstart/end | mousedown/up |
| 拖拽 | touchmove | mousedrag |
| 滚动 | 手势 | wheel |
| 多选 | 无 | Ctrl+点击 / Shift+范围 |
| 快捷键 | 无 | 1-9 数字键 / Q/W/E/R |

```javascript
// 键鼠事件适配示例
wx.onKeyDown?.((res) => {
  switch(res.keyCode) {
    case 27: // ESC
      showPauseMenu();
      break;
    case 32: // Space
      triggerAction();
      break;
  }
});

wx.onWheel?.((res) => {
  zoomCamera(res.deltaY > 0 ? -0.1 : 0.1);
});
```

## 三、适合PC端的品类

### 高匹配度品类

| 品类 | 为什么适合PC | 案例 |
|------|------------|------|
| 模拟经营 | 大屏幕展示更多内容 | 餐厅/农场/城市 |
| 策略塔防 | 键鼠操作更精准 | TD/RTS |
| 卡牌对战 | 多快捷键操作 | 自走棋/卡牌 |
| RPG | 长时长沉浸体验 | 文字RPG/放置RPG |
| 沙盒建造 | 键鼠建造效率高 | 像素建造 |

### 不适合PC端的品类

- 纯休闲消除类（触屏体验更好）
- 体感/重力感应类（PC无传感器）
- 极短时长的超休闲（PC用户期望更深度体验）

## 四、收益模型

### PC端用户特征（推测，需验证）

```
ARPU：约为移动端的 1.5-2 倍（付费意愿更强）
留存：7日留存比移动端高 10-15%（长时长游戏粘性强）
eCPM：略低于移动端（PC广告填充率较低）
内购：付费率更高，客单价更高
```

### 变现策略

```
PC端推荐变现组合：
├── 内购为主（60-70%）：大屏幕适合展示付费内容
├── 广告为辅（20-30%）：插屏+激励视频
└── 赛季/通行证（10%）：长线运营

定价策略：
├── PC端可定更高价格（用户付费能力强）
├── 推出PC专属礼包（大屏幕专属装饰）
└── 跨端同步（移动端付费PC端也可用）
```

## 五、技术注意事项

### 性能优势

```
PC端可以利用：
├── 更大内存（可加载更多资源）
├── 更强GPU（支持更复杂特效）
├── 稳定网络（有线网络延迟低）
└── 多核CPU（支持更复杂逻辑）
```

### 兼容性问题

```
需注意：
├── 不同 Windows 版本兼容性（Win10/Win11）
├── Mac 与 Windows 差异（金属 vs DirectX）
├── 显卡驱动差异（集成显卡性能弱）
└── 多显示器适配
```

## 六、跨端数据同步

### 同步策略

```
用户在移动端开始游戏 → PC端继续 → 数据必须同步
├── 方案1：云端存档（推荐）
│   └── 每次操作后自动上传存档到云数据库
├── 方案2：登录时全量同步
│   └── PC端登录时拉取最新存档
└── 方案3：实时同步
    └── WebSocket 实时同步（适合多人游戏）
```

### 冲突处理

```
存档冲突（移动端和PC端同时修改）：
├── 策略1：最后修改覆盖（简单但可能丢数据）
├── 策略2：字段级合并（复杂但数据完整）
└── 策略3：提示用户选择（体验差但安全）
```

## 七、PC端 vs 移动端运营差异

| 维度 | 移动端 | PC端 |
|------|--------|------|
| 内容更新频率 | 高（周更） | 中（双周更） |
| 活动设计 | 短时高频 | 长时深度 |
| 社交传播 | 微信分享 | 朋友圈+社群 |
| 用户反馈 | 评论/客服 | 更详细的Bug报告 |
| 数据分析 | 短会话指标 | 长会话指标 |
