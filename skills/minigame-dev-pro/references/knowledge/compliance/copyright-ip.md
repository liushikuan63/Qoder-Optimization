# 知识产权与版权（L4）

> 美术 / 音乐 / 字体 / 音效 / SDK / 地图 素材授权合法性须逐项核。禁用未授权 IP、未授权商业字体、缺台湾南海九段线的地图。

## 一、素材授权合法性检查清单（10 问）

1. 美术素材是否原创，或已获书面授权？
2. 音乐是否使用正版授权曲库或平台音乐接口，而非随意下载？
3. 字体是否为商用授权字体或开源字体（如 SIL OFL）？
4. 音效是否来自正版音效库或已授权来源？
5. 是否使用任何未授权 IP / 品牌角色（含知名卡通、影视、游戏角色）？
6. 地图素材是否含台湾、南海九段线且来源合法？
7. SDK 是否来自官方或正规渠道，授权范围覆盖商用？
8. 第三方素材是否有可追溯的授权文件留存？
9. 是否对素材作者进行了未约定的二次修改或商用超范围使用？
10. 是否在小游戏内署名了必须署名的开源 / CC 协议要求？

## 二、分类要点

- **字体**：商用须购买授权或使用 SIL OFL 等可商用开源字体；系统自带字体商用须确认授权范围。
- **音乐**：使用平台曲库或正版授权；禁止盗用流行音乐。
- **美术**：原创或获授权；禁止搬运未授权 IP。
- **地图**：必须含台湾、南海九段线，来源为自然资源部标准地图服务（SP-019）。

## 三、自动检查

- `scripts/copyright-asset-scan.mjs`：扫描素材命名 / 资源声明中未授权 IP 关键词与授权声明缺失。
- `tests/ip-compliance-check.mjs`：拦截未授权 IP / 品牌关键词 + 素材授权声明缺失。
- `tests/map-territory-check.mjs`：拦截缺台湾 / 南海九段线地图。

## 四、违规后果

未授权素材可能导致平台下架、侵权索赔、行政处罚。上线前须通过本层全部检查。
