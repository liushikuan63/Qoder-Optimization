## 附录：微信小游戏平台配置要点

在微信小游戏后台配置隐私保护指引时，需要注意：

1. **配置路径**：mp.weixin.qq.com → 设置 → 服务内容声明 → 用户隐私保护指引
2. **必选项**：根据实际使用的API勾选收集的信息类型
3. **常见勾选项**：
   - 头像昵称填写能力（`wx.chooseAvatar` / `input type="nickname"`）→ 勾选"用户信息（昵称、头像）"【`wx.getUserInfo` 已废弃，2022年10月起不再返回昵称/头像】
   - `wx.getStorage` → 勾选"设备信息"
   - 广告组件 → 勾选"广告交互信息"
4. **弹窗时机**：必须在首次收集信息前弹出隐私授权弹窗
5. **代码实现**：
```javascript
// 在app.js或首次需要隐私数据时
wx.requirePrivacyAuthorize({
  success() {
    // 用户同意，继续业务逻辑
  },
  fail() {
    // 用户拒绝，提供基础功能或提示
  }
})
```
