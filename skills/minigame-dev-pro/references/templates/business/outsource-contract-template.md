### 第三条 知识产权归属

#### 3.1 权属约定

**本项目所有交付物的知识产权（包括但不限于著作权、专利权、商标权及相关权益）自创作完成之日起即归甲方所有。**

具体包括但不限于：
1. 游戏程序源代码及目标代码的著作权
2. 游戏美术作品（角色、场景、UI、图标等）的著作权
3. 游戏音乐、音效作品的著作权
4. 游戏策划文档、设计文档的著作权
5. 游戏名称、Logo的相关权益
6. 基于本项目产生的所有衍生作品的权利

#### 3.2 乙方义务

1. 乙方确认本项目为委托创作，甲方为著作权人
2. 乙方不得将本项目的任何成果用于其他项目或提供给第三方
3. 乙方不得将本项目成果作为自己的作品进行展示、宣传（除非获得甲方书面同意）
4. 乙方应配合甲方办理软件著作权登记等相关手续
5. 如甲方需要，乙方应签署单独的《知识产权转让确认书》

#### 3.3 第三方素材

1. 乙方使用的任何第三方素材，必须具有合法的商用授权
2. 乙方应在交付时提供所有第三方素材的授权证明
3. 第三方素材的授权费用包含在合同总价中（除非另有约定）
4. 因乙方使用未授权素材导致的知识产权纠纷，由乙方承担全部责任

#### 3.4 侵权担保

乙方保证本项目交付物不侵犯任何第三方的知识产权。如因知识产权侵权给甲方造成损失，乙方应承担全部赔偿责任，包括但不限于：
- 甲方遭受的直接经济损失
- 甲方为应对侵权纠纷支出的合理费用（律师费、诉讼费等）
- 甲方因此被迫下架游戏导致的预期收益损失

### 第五条 验收标准

#### 5.1 验收流程

```
乙方提交交付物 → 甲方签收确认 → 甲方测试验收([7]个工作日) → 
├── 通过 → 签署验收确认书 → 支付对应款项
└── 不通过 → 书面列出问题 → 乙方修复([5]个工作日) → 重新验收
    └── 二次不通过 → 再次修复([5]个工作日) → 三次验收
        └── 三次仍不通过 → 甲方有权解除合同（见违约条款）
```

#### 5.2 验收内容

| 验收项 | 标准 | 验证方式 |
|--------|------|----------|
| 功能完整性 | 需求文档中所有功能均已实现 | 逐项对照测试 |
| 代码质量 | 可编译、有注释、结构清晰 | 代码审查 |
| 性能达标 | 帧率/加载/内存符合约定 | 真机测试 |
| 兼容性 | 约定机型无异常 | 多设备测试 |
| 美术质量 | 与确认的设计稿一致 | 视觉对照 |
| 交付物齐全 | 清单中所有项目均已交付 | 逐项清点 |
| 合规性 | 无违规内容，素材有授权 | 合规检查 |
