# 生产就绪清单（分域 · 147 条）

来源：用户提供的「vibe-coded 产品生产就绪清单」原文 147 条产品检查项，逐条保留、不删项。域分组、ID、适用条件、取证方式与默认严重度由本技能补充。

**ID 是报告契约的主键**：`readiness-report-check.cjs` 从本文件解析 ID 全集，报告必须逐项定性、一条不漏。**不得改号或删号**（会让历史报告失效）；新增检查项只能在域内追加新号。

**「缺失默认」＝该项完全缺失时的起点**，不是最终结论：实际严重度按现场证据调整。风险类别用于同严重度时的排序 tie-break，语义见 [report-contract.md](report-contract.md)。

**适用性优先**：先看「何时适用」，不满足就判 `not-applicable` 并写理由，**不要为了满足清单去加无用功能**。
