# 间歇性套件红项归因

## 适用

- 全量/聚合套件里只红一两项，单跑却是绿；需要判断是产品缺陷、测试夹具、负载还是 harness 漂移。
- 不适用于：已知失败的直接修复（→ `interrupted-test-repair`）、外部进程间歇卡死（→ `intermittent-hang-ab-triage`）、一般证据纪律（→ `verify-before-claim`）。

## 0. 纪律（先写下来）

- 不放宽判据凑绿；不把「重跑绿了」当修复。
- 复现不出就写「归因未定」并登记诊断缺口，不编根因。
- 套件运行期间零并行：不派子代理、不跑覆盖工具、不改共享文件。
- 结论分「机制已证明 / 仅为线索 / 未定」三档，证据引用本轮命令与退出码。

## 1. 定位失败与归属

1. 从持久化日志拿失败断言与退出码：`.exit`、`TEST_LOGS/` 逐测试日志、`summary.json`。不要只看终端末尾。
2. 归属排除：`git diff --name-only <绿HEAD>..<红HEAD>` 看失败测试与其依赖是否被改。
3. 字节同一性：`git rev-parse <绿>:<path>` 与 `<红>:<path>` 比对 blob；commit 范围相同不代表文件字节相同。
4. 判断「跑的是哪一版」：用**版本独有断言名**是否出现在分测日志；静态 `ok()` / `test()` 计数会被循环展开误导，不可作判据。辅以文件 mtime 与分测日志 mtime。

## 2. 机制证明（超时/被击杀）

- 超预算子进程常见签名：`status = null` + `signal = SIGTERM` + stdout/stderr 为空。
- 必须配正负对照：正常退出 `status = 0`；非零退出（如 exit 3）原样透传，证明 `null` 专指击杀。
- 不要只用耗时接近预算推断超时；要拿到机制证据。

## 3. 分层复现（环境保真度递增）

按顺序做，每层记录结果：

1. 独立沙箱路径（隔离 HOME/TEMP/APPDATA）。
2. 套件自己的 TEMP 环境。
3. 忠实复刻 runner：只保留 env 白名单（`PATH`、`SYSTEMROOT` 等）+ 隔离目录 + 与 runner 相同的 cwd。
4. 同环境连跑 N 次（如 20 次），统计红率。
5. 全量用例副本（不改冻结树）。
6. 真实前驱测试串行（前驱可能留下状态）。

插桩副本规则：

- 真源测试的基线断言若只打印 `exit=N`，套件内红项事后无法归因；生成一份**只加「失败时打印底层工具原文」**的副本探针，真源不动。
- 副本必须把 `__dirname` 钉回真源 scripts 目录，否则相对路径 ENOENT。
- 复刻 runner 的 env 白名单与 cwd，不要用当前 shell 的完整环境。
- 检查 `TEST_LOGS` 的逐件日志与 `summary.json`；聚合日志的 DIAGNOSTIC 可能截断底层原文。

## 4. 负载假设必须实测否证

- 不要只比较红/绿；直接量预算余量（脚本耗时 vs 超时预算，余量倍数写出来）。
- 两类负载画像 A/B：CPU 忙等、进程 churn。
- 点名负载源：统计并发会话证据目录在套件时间窗内的写入文件数，并取同窗口其他目录 = 0 作负对照。
- 对方会话的独立复跑（同用例数、同字节树、duration 倍差）只作佐证，标注「佐证 ≠ 本会话验收读数」。

## 5. 结论与收口

- 复现成功：给出机制、触发条件、证据链，再修根因；修后重跑同一判据。
- 复现不出：写「归因未定」+ 已排除项 + 诊断缺口；零并行重跑全量，如实记录。
- 区分 harness 漂移与产品缺陷；同一目标连败两次先升级怀疑层级（环境/语言/账号/数据/版本）。

## 6. 可失败验收

- 正对照：插桩副本在负载下能打印底层原文；失败断言可定位到具体测试。
- 负对照：绿 HEAD 的同一文件 blob 必须相同；非零退出必须原样透传；不存在的前驱必须不产生红项。
- 负载否证：余量倍数可计算；无并发写入的时间窗必须看不到同样红项。

## 常见坑

| 现象 | 原因 / 处理 |
|---|---|
| 事后无法归因 | 真源断言只打 exit 码；用插桩副本打印 `r.out` |
| 副本 ENOENT | `__dirname` 指向副本目录；钉回真源 scripts |
| 复现脚本环境不对 | 未复刻 runner env 白名单与 cwd |
| 静态断言计数推断版本 | 循环展开导致计数失真；用版本独有断言名 |
| 探针钉死行号假红 | 日志位移；按断言名/内容定位 |
| 负载假设看起来成立 | 未量余量；直接测耗时与预算 |
| 套件期间并行 | 违反零并行口径；红项归因被污染 |
| 重跑绿了就算修复 | 根因未明；只能记「本轮未复现」 |
