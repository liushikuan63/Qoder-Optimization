# 交付前返工防线（rework guard）

`../SKILL.md` 十一节的可执行展开。用途：用户已抱怨过「检查不细致 / 反复返工」时，把返工高发形态变成逐条可失败判据，而不是再写一遍"已验证"。

## 1. 返工形态与对应判据

| 形态 | 为什么会返工 | 可失败判据（本轮） | 负对照 |
|---|---|---|---|
| 只验主路径 | 列表 → 详情 → 编辑 → 保存是四条路径，只点首页 | 每个改动路由各有一条真实运行记录 | 故意跳过一条路径时矩阵缺行必须被发现 |
| 漏并列需求 | 用户一句话里有三个并列项，只实现两个 | 需求逐条映射表行数 == 原话可验收句数 | 删掉一条映射，审计必须判红 |
| 漏影响面 | 改了共享组件，只有当前页验证过 | 调用方/孪生入口清单逐项有证据或显式未覆盖 | 清单少一个同族入口时应能被指出 |
| 旧入口坏掉 | 新菜单/新路由改了推导逻辑，旧菜单不高亮或旧表单报错 | 旧入口各走通一次并截图 | 只验证新入口时旧入口用例必须红 |
| 最后一轮改动后没复跑 | 改完又动了一行，用的还是之前的绿灯 | 证据 `finishedAt` ≥ `lastChangeAt` | 把证据时间改早，审计必须判红 |
| 假绿 | 断言读自己的夹具、空集合、刚写入的值 | 断言必须读被测系统；正负对照可区分 | 摘掉被测分支，判据必须变红 |
| 环境口径差异 | 在 dev 账号/中文界面/本地数据下全绿，用户环境不同 | 记录界面语言、账号、数据状态、dev vs 现役 | 换一个环境跑，结论必须显式不同 |
| 只修表象 | 用户报 A，修了 A 的按钮，根因在接口仍存在 | 复现原症状 → 定位根因 → 同路径回归 | 只改 UI 文案时根因判据必须仍红 |

## 2. 需求覆盖矩阵（中大型交付必填）

```
| 需求（原话/可验收句） | 改动位置 | 证据（命令/截图/接口） | 状态 |
|---|---|---|---|
| ... | src/... | 命令 + 退出码 / 截图路径 | verified / unverified + 原因 |
```

规则：

- 原话中的并列项、"顺便"项、否定项各占一行；一行的"证据"只能证明这一行。
- 状态只写 `verified` 或 `unverified + 原因`；不写"基本完成 / 应该没问题"。
- 行数少于可验收句数即未完成，不因其余行全绿而抵消。

## 3. 落到 evidence-audit

把矩阵映射成报告字段，而不是只写在回复里：

```json
{
  "schema": 1, "task": "本轮任务", "runId": "本轮唯一标识", "cwd": "本轮工作目录",
  "lastChangeAt": "2026-11-17T10:00:00Z",
  "requirements": [
    { "id": "req-1", "text": "需求原话或可验收句", "checkIds": ["contract"] }
  ],
  "checks": [
    { "id": "contract", "claim": "可失败声明", "status": "verified", "requiredLevel": "static",
      "changedVariable": "仅换成已知缺陷输入",
      "positive": { "file": "positive.json", "sha256": "<64位SHA256>", "expect": { "exitCode": 0 } },
      "negative": { "file": "negative.json", "sha256": "<64位SHA256>", "expect": { "exitCode": 1 } } }
  ]
}
```

- 证据记录（`positive.json` / `negative.json`）加 `finishedAt`（ISO 时间），必须不早于 `lastChangeAt`。
- `requirements` 里没有映射、映射到未验证检查或检查判红，审计分别返回 FAIL / INCOMPLETE，不会因为其它行绿而放行。
- 命令：`node ~/.qoder/scripts/evidence-audit.cjs <report.json>`，只有退出 0 才可宣布完成。

## 4. 何时可以不走完整报告

- 小于三步、可逆的本地操作：一条属于本轮、能失败的判据 + 负对照即可。
- 纯问答、只读审阅：不要求报告，但结论要能指出证据入口。
- 一旦用户指出过"检查不细致"，同一任务后续交付默认按本文件执行，直到该任务结束。
